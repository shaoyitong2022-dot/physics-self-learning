# 物理自学手册

> 物理不是一门"听课"的学科，是一门"算题"的学科。

一份面向自学者与转行者的物理学开源学习路线与资源索引。

在线阅读（待部署）：`https://physdiy.wiki`

## 与 CS 自学指南的关键差异

本项目受 [cs-self-learning](https://github.com/PKUFlyingPig/cs-self-learning) 启发，但物理自学的资源生态与 CS 有本质不同，因此结构做了针对性调整：

| 维度 | CS | 物理 | 本手册的处理 |
| --- | --- | --- | --- |
| 反馈机制 | autograder 自动判分 | 基本没有，靠公开解答库 | 单列[习题与解答](docs/习题与解答.md)页，作为核心页面 |
| 大作业 | 上千行 project | 教材习题 | 用[计算物理项目](docs/计算物理/项目清单.md)补上"可展示成果" |
| 数学依赖 | 前置几门课即可 | 贯穿全程，随时卡壳 | 给出数学↔物理的[对应表](docs/学习规划.md)，按需补 |
| 实验环节 | 无 | 有，且无法在家做 | 明确标注缺口，用仿真 + 计算替代 |
| 语言 | 几乎全英文 | 中文资源一流 | 中英并重收录 |

## 如何贡献

1. 新增一门课 / 一个主题：复制 [`template.md`](template.md) 填写
2. 在 `mkdocs.yml` 的 `nav` 中登记路径
3. 在 [`学习规划.md`](docs/学习规划.md) 的对应模块补一句导语
4. 提交 Pull Request

贡献规范：

- **资源链接必须真实可访问**，提交前请点一遍
- 标注资源的**许可状态**，不接受盗版扫描件的直链
- 涉及中英混排，参考[中文文案排版指北](https://github.com/sparanoid/chinese-copywriting-guidelines)
