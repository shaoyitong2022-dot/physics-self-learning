# 科学计算栈

## Python（推荐首选）

| 库 | 用途 |
| --- | --- |
| NumPy | 数组、线性代数、FFT |
| SciPy | 积分、优化、ODE、特殊函数、`scipy.linalg.eigh`（量子力学对角化必备） |
| Matplotlib | 绘图，物理图要会用 `errorbar`、`contour`、`imshow` |
| SymPy | 符号推导，验证手算结果 |
| JAX | 自动微分，做变分方法、优化类项目极强 |
| emcee | MCMC 采样，参数估计与误差分析 |
| lmfit | 曲线拟合，比裸 `curve_fit` 好用 |
| h5py / pandas | 大规模数值结果存储与整理 |

安装：

```bash
pip install numpy scipy matplotlib sympy jax emcee lmfit
```

## Julia（高级项目推荐）

- 微分方程生态世界第一：`DifferentialEquations.jl`
- 性能接近 C，语法接近 Python
- 适合做长时间积分、大规模模拟（第 14、19、25 题）

## Mathematica（符号推导）

- 商业软件，但学生版/学校授权常见
- 符号积分、特殊函数、张量计算的效率高于手工
- 用途定位：**验证手算**，不要用它替代推导

## Fortran / C++（遗产代码）

- 高能、天体、格点 QCD 等老牌领域大量遗留 Fortran 代码
- 不必主动学，但读得懂是加分项

## 环境建议

!!! tip "用 conda 或 uv，不要用系统 Python"
    Windows 上编译科学计算包容易出问题。推荐用 Anaconda（你机器上已装）创建独立环境：

    ```bash
    conda create -n physics python=3.11 numpy scipy matplotlib jupyter
    conda activate physics
    ```

## 版本与可复现

- 每个项目固定依赖版本（`requirements.txt` 或 `environment.yml`）
- Notebook 要能从头跑通（`Kernel → Restart & Run All` 检查一遍）
