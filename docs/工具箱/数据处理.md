# 数据处理与误差分析

!!! note "这一页是物理区别于 CS 的地方"
    程序员处理的数据通常是精确的；物理的数据**必须带不确定度**。没有误差棒的测量结果在物理学里是没有意义的。这块内容在多数自学路线里被忽略，但它是判断一个人是否受过物理训练的分水岭。

## 核心内容

| 主题 | 要点 |
| --- | --- |
| 误差分类 | 系统误差 vs 随机误差；精度 vs 准确度 |
| 不确定度传播 | $\sigma_f^2 = \sum_i \left(\frac{\partial f}{\partial x_i}\right)^2 \sigma_{x_i}^2$ |
| 加权平均 | 不同精度测量的合并 |
| 最小二乘拟合 | 线性与非线性；$\chi^2$ 检验 |
| 拟合优度 | 约化 $\chi^2_\nu \approx 1$ 才说明模型与误差估计自洽 |
| 残差分析 | 残差有结构 = 模型错了 |
| 蒙特卡洛误差传播 | 解析传播失效时用抽样 |
| 贝叶斯参数估计 | `emcee` 做后验采样 |

## 工具

- **`scipy.optimize.curve_fit`**　基础拟合，注意它默认不处理 x 方向误差
- **`lmfit`**　参数约束、复合模型更好用
- **`emcee`**　MCMC，做完整后验与参数相关性
- **`uncertainties`**　自动误差传播的 Python 库
- **ROOT**　高能物理标准框架，体量大，进入该方向再学
