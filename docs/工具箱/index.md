# 工具箱

物理自学者的工具链和 CS 不同：重心在**排版、数值计算、数据处理、文献检索**四项。

| 工具 | 用途 | 优先级 |
| --- | --- | --- |
| [LaTeX](LaTeX.md) | 写公式、记解答、写报告 | ★★★ 必须 |
| [科学计算栈](科学计算.md) | Python / NumPy / Julia / Mathematica | ★★★ 必须 |
| [数据处理与误差分析](数据处理.md) | 拟合、误差传播、不确定度 | ★★ 做实验或数据处理时 |
| [文献检索](文献检索.md) | arXiv、INSPIRE-HEP、Google Scholar | ★★ 进入阶段 3 后 |

!!! tip "最小启动集"
    如果你只想马上开始：装一个 TeX 发行版（或直接用 Overleaf）+ Python 的 NumPy/SciPy/Matplotlib，就够了。其余按需再补。
