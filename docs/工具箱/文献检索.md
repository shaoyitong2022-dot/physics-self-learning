# 文献检索

进入阶段 3（开始读论文）后才需要，但早一点熟悉能大幅降低"从教材到前沿"的落差感。

## 主要入口

| 平台 | 覆盖范围 | 说明 |
| --- | --- | --- |
| **arXiv** | 物理全领域预印本 | 最常用。按 `cond-mat`、`hep-th`、`quant-ph`、`gr-qc`、`astro-ph` 等分类订阅 |
| **INSPIRE-HEP** | 高能物理 | 高能方向的事实标准，引用关系与作者页做得极好 |
| **Google Scholar** | 全领域 | 检索与引用追踪 |
| **APS / IOP / AIP** | 期刊正式版 | 学校有订阅时用；注意预印本与正式版可能有差异 |
| **Semantic Scholar / Connected Papers** | 跨领域 | 做文献图谱，快速摸清一个陌生方向 |

## 教科书 → 论文的过渡路径

这是自学者最容易卡住的环节。建议按这个顺序：

1. **找综述 / Review**。搜 "(topic) review arXiv"，或看 *Reviews of Modern Physics*、*Physics Reports* 上的文章。
2. **找经典原始论文**。每个方向都有几篇必读原文（如 Ising 模型、BCS 理论、Kibble–Zurek 机制），教材里通常会引用。
3. **看近三年的博士论文**。学位论文的引言部分往往比论文更好读，是绝佳的入门材料。
4. **顺着引用链往回走**。用 INSPIRE 或 Scholar 的引用图谱，找到奠基性工作。
5. **最后读最新进展**。

## 阅读方法

!!! tip "论文不要从头读到尾"
    正确顺序：**摘要 → 图表 → 结论 → 再决定要不要读正文**。一篇论文平均值得你花的时间是逐步增加的，第一次读一篇陌生的论文超过 2 小时还没懂，通常是前置知识不够，应该退回去补教材而不是硬读。

## 管理

- **Zotero**（开源，推荐）或 Mendeley 管理文献
- 用 BibTeX + LaTeX 引用
- 建立自己的"论文笔记库"：每篇记一句话总结 + 用到的关键方法

## 需要警惕的

- arXiv 上的文章**未经同行评审**，初学者难以分辨质量
- 引用量高的不等于正确，只是影响大
- 遇到"这篇论文说 X"时，尽量追溯到原始出处，二手引用常有失真
