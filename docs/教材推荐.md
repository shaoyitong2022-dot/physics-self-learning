# 教材推荐

按"定位"分类，而不是按难度排序。同一格内的书可以互换，不必都读。

## 贯穿：数学工具

| 定位 | 书 | 说明 |
| --- | --- | --- |
| **用中学**（首选） | Boas《Mathematical Methods in the Physical Sciences》 | 物理系学生的数学百科。卡在哪个数学点就翻哪一章，比回头重修高效得多 |
| 系统学 | Arfken & Weber《Mathematical Methods for Physicists》 | 更全更深，适合作为参考书 |
| 复变与积分变换 | Brown & Churchill《Complex Variables and Applications》 | 留数定理讲得清楚 |
| 偏微分方程 | Haberman《Applied Partial Differential Equations》 | 分离变量、本征函数展开讲得极好 |
| 线性代数（直觉） | 3Blue1Brown《线性代数的本质》视频系列 | 建立几何直觉，两小时看完 |
| 线性代数（运算） | Strang MIT 18.06 | 标准课 |
| 群论入门 | Zee《Group Theory in a Nutshell for Physicists》 | 物理学家写给物理学家的群论 |

## 普通物理

| 定位 | 书 | 说明 |
| --- | --- | --- |
| **通识 / 直觉** | Feynman《物理学讲义》I–III | 在线免费（feynmanlectures.caltech.edu）。不适合初学做题，但学完一遍后读它建立直觉 |

| 习题（中文） | 《物理学难题集萃》 | 极硬，适合拔高 |

## 理论力学

| 定位 | 书 | 说明 |
| --- | --- | --- |
| **过渡首选** | Morin《Introduction to Classical Mechanics》 | Harvard 教材，习题设计极好且有分层，是通往 Goldstein 的最佳桥梁 |
| 标准 | Goldstein《Classical Mechanics》 | 研究生标准教材，正则变换与哈密顿–雅可比讲得透 |
| 中文 | 周衍柏《理论力学教程》 | 国内常用教材 |
| 参考 | Landau《力学》（Course of Theoretical Physics 卷 1） | 题少而精，视角极高，建议第二遍读 |
| 入门视频 | Susskind《Classical Mechanics》（The Theoretical Minimum） | 配合 Landau 看效果很好 |

## 使用建议

1. **同一格不要再买第二本**。教材的边际收益递减极快，横向铺开不如纵向做透。
2. **中英文对照不是浪费**。中文教材讲得清楚的地方可以快速过，英文教材的习题质量通常更高——两者混用是中文自学者的独特优势。
3. **警惕盗版扫描件直链**。本站不提供盗版链接，但会标注哪些书有合法的免费在线版本。
