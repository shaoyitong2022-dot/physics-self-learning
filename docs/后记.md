# 后记

## 关于这本手册的局限

必须诚实说明几件事：

1. **资源链接会腐烂**。课程网站会改版、教材会出新版本、视频会被下架。这是所有资源索引类项目的宿命。如果你发现失效链接，请提 issue 或 PR —— 这本身就是最有价值的贡献。
2. **作者视角必然有偏**。任何一份"学习路线"都带有作者的知识背景和审美偏好。本手册偏向理论物理的训练路径，对实验物理的覆盖明显不足（这是自学实验物理的结构性困难，不完全是主观选择）。
3. **没有覆盖到的方向还有很多**：生物物理、软物质、地球物理、等离子体、核物理、量子信息（独立成体系的）、材料物理……这些是后续待补的内容。

## 自学物理最该记住的三件事

**一、做题量决定上限。**
物理不是看懂的学科，是算会的学科。看懂推导和能独立推出结果之间，隔着几十道题的距离。

**二、数学是工具，不是门槛。**
不要试图先把数学学完再学物理。数学永远领先物理半步，卡在哪补哪。在实分析里耗三个月，是自学物理最经典的失败方式。

**三、给自己造反馈。**
没有助教判卷、没有实验室，这是物理自学真正的困难。解决办法只有两个：用公开的[习题解答](习题与解答.md)库核对，用[计算项目](计算物理/项目清单.md)让代码告诉你对不对。
