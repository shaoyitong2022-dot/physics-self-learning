# 轨道 0　同步补强

> **适合所有人，尤其是低年级。这是其他所有轨道的地基。**

## 适合谁

- 某门课上课听不懂、课后题做不出来，想**换一套资源重学一遍**
- 感觉自己基础不牢，想回头把漏洞补上
- 大一大二，还没确定方向

**不适合谁**：四大力学已经扎实、成绩稳定靠前的同学——你们应该直接选 A–G 的方向轨道。

## 核心思路

!!! note "这条轨道的关键判断"
    课内学不好，**90% 的情况不是你不聪明，而是教材或讲课方式不适合你**。换一套公认的好资源重学一遍，往往比你硬啃原教材十遍都有效。

    这不是逃避，是资源优化。Griffiths 之所以被全世界物理系使用，就是因为他讲得比大多数教材清楚——**用好教材不是作弊**。

## 按科目：课内没学明白时，换什么

| 卡住的课 | 换这套资源 | 具体做法 |
| --- | --- | --- |
| **力学** | Morin《Introduction to Classical Mechanics》 | 习题分层极好，直接从"难题"部分开始做，做完回头看哪里漏了 |
| **电磁学** | Griffiths 第 1–7 章 | 讲得比普物教材清楚得多。若数学够，直接用它替代 |
| **热学** | Schroeder 第 1 章 + Fermi《Thermodynamics》 | Fermi 那本极薄，一下午能读完，讲得极清楚 |
| **光学** | 先看 MIT 8.03（振动与波），再回光学 | 光学本质是波动，波动没学好光学一定卡 |
| **近代物理** | Griffiths 量子力学第 1 章 + 杨福家《原子物理学》 | 先建立"量子化"的观念 |
| **线性代数** | 3Blue1Brown 建直觉 + MIT 18.06 练运算 | 这是量子力学的前置，优先度极高 |
| **数学物理方法** | Boas，卡哪查哪 | 不要通读 Arfken，那是另一种拖延 |
| **理论力学** | Morin → Goldstein | 若 Goldstein 推不动，先退到 Morin |
| **电动力学** | Griffiths（必选） | 第 3 章边值问题是全书枢纽，必须做透 |
| **量子力学** | Griffiths → Sakurai/Shankar | 见[量子力学](../四大力学/量子力学.md) |
| **统计物理** | Schroeder（必选） | 自学者最友好的一本 |

## 时间预算

| 每周投入 | 能补多少 |
| --- | --- |
| 5 小时 | 一学期补牢一门课（只做题，不看新课） |
| 10 小时 | 一学期补牢一门课 + 重学一遍核心章节 |
| 15 小时+ | 假期集中突破，4–6 周可重学一门四大课 |

!!! warning "一次只补一门"
    最常见的错误是同时开三门"重学计划"，结果哪门都没走完。**一次只补一门，补完再换下一门。**

## 检验标准

补到什么程度算过关？用可验证的标准，不要靠感觉：

| 科目 | 过关标准 |
| --- | --- |
| 力学 | 能解出 Morin 难题部分 50% |
| 电磁学 | Griffiths 每章习题做完 70%，第 3 章能做边值问题 |
| 量子力学 | 独立推出谐振子升降算符解与氢原子能级 |
| 统计物理 | 独立算出几个非平凡模型的配分函数 |
| 电动力学 | Griffiths 第 3 章大部分习题能独立做 |

## 出口

走完这条轨道，你应该具备：

- 四大力学的扎实基础（不是"学过"，是"会算"）
- 一份用 LaTeX 记录的习题归档（这是你的复习材料和作品）
- 若干个计算项目（见[项目清单](../计算物理/项目清单.md)）

之后就可以选方向轨道了。

## 常见坑

- **从头再看一遍教材** —— 这是最没效率的补法。应该直接做题，做完发现哪里不会，再针对性回看。
- **换教材换得太频繁** —— 选定一本，做完 70% 再考虑换。中途换教材是拖延的高级形式。
- **只补不做题** —— 看懂推导和会做是两回事。这条轨道的**全部意义都在做题上**。
- **同时补数学和物理** —— 数学只补当下用到的那一块，不要开独立的"数学补强计划"。
