# 轨道 D2　量子信息

!!! tip "当下最热的方向之一"
    量子计算是少数几个**产业与学术同步爆发**的方向。物理背景在这里不是"可以转过去"，而是**本来就最对口**。

## 核心内容路径

**第一层　量子信息基础**
量子比特与布洛赫球 → 密度矩阵与混合态 → 量子门与电路 → 测量 → 纠缠与 Bell 不等式 → 量子信道

**第二层　量子计算**
量子算法（Deutsch–Jozsa、Grover、Shor）→ 量子傅里叶变换 → 量子复杂度初步 → 变分量子算法（VQE、QAOA）

**第三层　量子纠错与硬件**
量子噪声与退相干 → 纠错码（Shor 码、表面码）→ 容错阈值定理 → 物理实现（超导、离子阱、中性原子、光子）

**第四层　专题**
量子机器学习 → 量子模拟 → 量子密码 → 量子 advantage 的前沿争论

## 为什么物理背景吃香

量子信息的硬件端（超导比特、离子阱、中性原子阵列）**本质就是 AMO 物理**。而理论端需要的是：

- 线性代数（物理系训练扎实）
- 量子力学（这是本行）
- 对退相干、开放系统的理解（统计物理训练）

CS 出身的人做量子算法有优势，做硬件和物理实现就明显吃力。**这是物理人的主场。**

## 配套计算项目

- 量子电路的数值模拟（自己写一个简单的模拟器）
- Bell 不等式与纠缠熵的计算
- Grover 算法的实现与验证
- 密度矩阵的演化（退相干）
- 变分量子本征求解器（VQE）求小分子基态能量

## 常见坑

- **只看科普不学数学** —— 量子计算是科普重灾区，"量子比特同时是 0 和 1"这种话对你理解没有任何帮助
- **跳过量子力学基础直接学算法** —— 你会不知道自己在算什么
- **只学算法不碰硬件** —— 如果你有物理背景却去做纯 CS 向的量子算法，等于放弃了你的优势
- **忽视统计物理** —— 退相干与开放系统是量子纠错的核心，靠的是统计物理训练
