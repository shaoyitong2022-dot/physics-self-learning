# 轨道 H　生物物理

## 轨道信息

| | |
|---|---|
| **适合谁** | 对生命现象的物理机制感兴趣；想要交叉背景；喜欢" messy 但有真实问题"的领域 |
| **不适合谁** | 追求理论优美与封闭体系的人（生物系统天生 messy） |
| **起点要求** | 统计物理（**最重要**）、热力学、流体力学基础 |
| **时间预算** | 四大力学 + 统计物理之后，约 12 个月 |
| **出口** | 生物物理课题组；生物技术、药物设计、医学物理 |
| **产业接口** | ★★★★☆ 生物医药产业庞大，且与 AI 交叉（AlphaFold 一类） |

!!! note "统计物理是这门课的核心"
    生物物理和传统物理最大的不同：它处理的都是**强涨落、远离平衡、小系统**的问题。这些恰恰是统计物理最擅长的。

    所以生物物理好的组，往往有很深的统计物理背景。

## 核心内容路径

**第一层　基础**
生物大分子（蛋白质、核酸、膜）→ 分子间相互作用 → 水溶液中的物理 → 熵与自由能在生物学中的角色

**第二层　核心机制**
随机过程与布朗运动 → 扩散与输运 → 分子马达 → 生物膜的物理 → 蛋白质折叠 → 酶动力学

**第三层　系统层面**
神经网络的物理 → 群体行为与活性物质 → 系统生物学 → 进化动力学的物理模型

## 为什么值得考虑

- **问题极多且真实**，不像高能理论那样岗位稀缺
- **与 AI 交叉紧密**（蛋白质结构预测、药物设计），薪酬天花板高
- 物理背景在这个领域是**稀缺的**——生物背景的人数学训练普遍不足

## 配套计算项目

- 布朗运动与随机行走模拟
- 分子马达的棘轮模型
- 蛋白质折叠的简化格子模型（HP 模型）
- 活性物质的集体运动（Vicsek 模型）
- SIR 传染病模型与渗流

## 常见坑

- **以为需要先学生物** —— 不需要。需要的是统计物理，生物知识边做边补
- **被生物学术语吓到** —— 大部分生物学术语对应的是很简单的物理概念
- **追求精确解** —— 生物系统里数量级估算和标度分析比精确解重要得多
