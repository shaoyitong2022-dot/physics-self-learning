# 轨道 F　考研

> 这是唯一一条**以应试为唯一目标**的轨道。目标明确：考上去。

## 适合谁

- 大三，目标是国内硕士/博士，走考研这条路
- 成绩没到保研线，或者想换学校/换专业

**不适合谁**：能保研的同学（保研不占备考时间，性价比高得多，见[升学路径](../升学路径.md)）。

## 核心思路

!!! note "考研和学物理是两件事"
    考研考的是**在限定时间内做出有标准答案的题**。它和"真正学懂物理"高度相关，但不完全等价。

    这条轨道的特殊性在于：**要刻意训练速度和熟练度**，而不仅仅是理解。

## 常见考试科目

不同学校差异很大，**务必先查清目标院校的考试科目和参考书**（这是第一步，也是最重要的一步）。常见组合：

| 组合 | 科目 |
| --- | --- |
| 典型一 | 政治 + 英语一 + 数学一 + 普通物理（力热电光原） |
| 典型二 | 政治 + 英语一 + 数学一 + 量子力学 |
| 典型三 | 政治 + 英语一 + 两门专业课（如量子力学 + 电动力学） |
| 典型四 | 政治 + 英语二 + 数学二 + 专业课（专硕） |

!!! danger "先查招生简章"
    每年 9 月发布当年简章。**科目、参考书、招生人数都可能变**，一定要以目标院校研招网的最新信息为准。

## 分阶段安排

### 第一阶段：基础（3–6 个月）

| 科目 | 任务 |
| --- | --- |
| 数学 | 高数、线代、概率论过一遍，做基础题 |
| 英语 | 单词 + 长难句，开始做阅读 |
| 专业课 | 按目标院校指定教材过一遍，做课后题 |
| 政治 | 暂不开始 |

### 第二阶段：强化（3–4 个月）

| 科目 | 任务 |
| --- | --- |
| 数学 | 大量刷题，建立题型库 |
| 英语 | 真题为主，重点阅读与作文 |
| 专业课 | **做目标院校历年真题**（最重要） |
| 政治 | 开始，先马原 |

### 第三阶段：冲刺（2 个月）

- 全真模拟（严格计时）
- 政治冲刺背诵
- 专业课真题反复做

## 物理专业课怎么准备

### 普通物理

- 用你本科学得最熟的那套教材快速过一遍
- 重点做**计算题**，不做概念题
- 《物理学难题集萃》适合拔高，但**不要沉溺**——考研题难度通常低于它

### 量子力学（最常见的高阶专业课）

- 曾谨言或 Griffiths，看目标院校指定哪套
- **重点题型**：一维势阱/势垒、谐振子、角动量、氢原子、微扰论、自旋
- 这些题型相对固定，**把每种题型的解法练到条件反射**

### 电动力学

- 郭硕鸿或 Griffiths
- 重点：边值问题、多极展开、电磁波

!!! tip "真题是最有价值的资料"
    目标院校的历年真题能告诉你：考什么、难度如何、题型怎样。**至少做最近 10 年的**，做完你会发现重复率很高。

## 时间预算

| 每周投入 | 说明 |
| --- | --- |
| 20–30 小时 | 备考期的常态（大三下–大四上） |
| 40 小时+ | 冲刺期 |

!!! warning "不要拉长战线"
    考研备考超过一年会严重消耗。**6–9 个月足够**，战线太长反而崩。

## 检验标准

- [ ] 历年真题能做对 70% 以上
- [ ] 数学能在 3 小时内做完一套卷
- [ ] 专业课每种题型都有固定解法

## 出口

- 国内硕士/博士项目
- 如果没考上：调剂、二战、或转向[轨道 E（计算·AI·量化）](计算AI量化.md)

## 常见坑

- **不查招生简章就复习** —— 可能复习错科目，这是最惨的
- **沉溺难题** —— 考研考的是熟练度，不是竞赛
- **忽视英语和政治** —— 这两科是"投入产出比"最确定的，别拖到最后
- **不做真题** —— 真题的价值高于任何模拟题
- **战线过长** —— 一年以上几乎必崩
- **备考期间完全放弃其他** —— 如果考研失败需要有退路，建议同时保持基本的编程能力和项目
