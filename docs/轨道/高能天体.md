# 轨道 C　高能粒子与场论

## 轨道信息

| | |
|---|---|
| **适合谁** | 对基本粒子、量子场论、对称性有强烈兴趣；数学能力强；能承受长期无反馈 |
| **不适合谁** | **主要目标是高薪的人**（见[出路与规划](../出路与规划.md)——这条路的产业接口最弱） |
| **起点要求** | 四大力学 + [量子场论](../进阶理论/量子场论.md) + [群论](../进阶理论/群论.md) |
| **时间预算** | 最长的一条，从零到能进组通常 3 年以上 |
| **出口** | 学术为主（高校、研究所）；转行者多靠编程与建模能力硬转 |
| **产业接口** | ★☆☆☆☆ 最弱 |

**特点**：物理学中最"纯粹"、数学最深的分支。代价是**反馈周期极长** —— 可能投入一年才做出第一个独立计算。

!!! warning "自学难度最高"
    这个方向对自学者最不友好：知识栈最长（需要 QFT + 群论 + 微分几何），且几乎没有可以在家验证的实验。**入坑前请认真评估自己的时间预算。**

## 核心内容路径

**第一层　粒子物理基础**
标准模型概览 → 费米子与玻色子 → 相互作用与规范玻色子 → Feynman 图与散射截面 → 轻子与夸克 → 强子谱与 QCD 初步

**第二层　规范场论**
规范对称性 → 非阿贝尔规范场 → 路径积分量子化 → 重整化与跑动耦合 → 自发对称破缺与 Higgs 机制 → 标准模型的完整构造

**第三层　前沿专题**
超出标准模型的物理 → 超对称 → 弦论（选学）→ 格点 QCD → 有效场论 → 散射振幅新方法

## 现实提醒

- **纯自学进入高能理论研究几乎不可能**。这个方向强烈依赖导师与同行讨论，建议至少要在读研/博士阶段进入。
- 如果目标是"理解"而非"做研究"，Griffiths 粒子物理 + Tong QFT 讲义就已经能达到相当好的理解水平。
- 计算方向（格点 QCD、唯象拟合）是自学者相对可行的切入点。

## 常见坑

- **跳过 Griffiths 的粒子物理直接上 Peskin** —— 你会不知道自己在算什么
- **沉迷弦论科普** —— 科普和实际的弦论研究相差十万八千里
- 长期只有输入没有输出 —— 至少要用符号计算工具复现一些标准结果
