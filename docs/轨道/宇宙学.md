# 轨道 C2　天体与宇宙学

## 轨道信息

| | |
|---|---|
| **适合谁** | 对宇宙学、天体物理感兴趣；喜欢用数据说话；不排斥学广义相对论 |
| **不适合谁** | 不愿学 GR 的人（现代宇宙学离不开它）；对数据分析没兴趣的人 |
| **起点要求** | 四大力学 + [广义相对论](../进阶理论/广义相对论.md)（天体物理方向要求略低） |
| **时间预算** | 12–18 个月 |
| **出口** | 天文台、宇宙学课题组；退路靠数据分析能力转向数据科学 |
| **产业接口** | ★★☆☆☆ 弱，但数据分析技能可迁移 |

!!! tip "对自学者意外地友好"
    这个方向的**观测数据高度公开**（Planck、SDSS、LIGO、Gaia 都能直接下载），意味着你真的可以在自己的电脑上做出有意义的分析——这在物理各方向里很少见。

**特点**：观测数据高度公开（很多数据集可以直接下载分析），是自学者**最容易做出真实工作**的方向之一。

## 核心内容路径

**天体物理**
恒星结构与演化 → 辐射转移 → 星际介质 → 星系动力学 → 致密天体（白矮星、中子星、黑洞）→ 吸积盘

**宇宙学**
FLRW 度规 → 宇宙学红移与距离 → 热历史（BBN、复合）→ 结构形成 → CMB → 暴胀 → 暗物质与暗能量

## 教材

| 层次 | 教材 | 说明 |
| --- | --- | --- |
| 天文入门 | Carroll & Ostlie《An Introduction to Modern Astrophysics》 | 大部头，覆盖面极广，适合作为参考与入门 |
| 恒星物理 | Kippenhahn《Stellar Structure and Evolution》 | 标准 |
| 宇宙学（首选） | **Dodelson《Modern Cosmology》** | 现代标准教材，讲得清楚 |
| 宇宙学（进阶） | Weinberg《Cosmology》 | 权威、全面、偏难 |
| 宇宙学（简明） | Barbara Ryden《Introduction to Cosmology》 | 极适合入门，薄而清楚 |
| GR 基础 | Carroll《Spacetime and Geometry》 | 宇宙学必备 |
| 中文 | 俞允强《物理宇宙学讲义》 | 中文佳作 |

## 为什么对自学者友好

- **数据是公开的**：SDSS、Planck、LIGO、Gaia 的数据都可以直接下载
- **有现成工具链**：Astropy、HEALPix、emcee
- **可以做出真实的分析**：哪怕只是复现一张论文里的图，也是实实在在的训练

!!! tip "推荐的一条务实路线"
    学完 Ryden → Dodelson → 然后去下载 Planck 或 SDSS 的公开数据，复现一个已知结果。这一步的收获超过再读两本教材。

## 配套计算项目

- N 体宇宙学模拟（简化版）
- 光线在 Schwarzschild 度规中的偏折
- CMB 功率谱计算（用 CAMB/CLASS 或简化版本）
- 恒星结构方程的数值积分

## 常见坑

- **不看数据只学理论** —— 这个方向的生命力在于与观测对照
- **被科普吸引却不愿学 GR** —— 现代宇宙学离不开广义相对论
- 忽略统计与误差分析 —— 宇宙学是数据驱动的，统计功底决定上限
