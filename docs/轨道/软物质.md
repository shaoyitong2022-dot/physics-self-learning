# 轨道 I　软物质与复杂流体

## 轨道信息

| | |
|---|---|
| **适合谁** | 对"日常物质的物理"感兴趣（聚合物、胶体、液晶、泡沫、颗粒物质）；喜欢看得见摸得着的物理 |
| **不适合谁** | 只想做纯理论的人 |
| **起点要求** | 统计物理 + 热力学 + 流体力学基础 |
| **时间预算** | 四大力学之后，约 8–12 个月 |
| **出口** | 软物质课题组；材料、化工、食品、化妆品、医药产业 |
| **产业接口** | ★★★★☆ 应用面极广 |

!!! tip "被低估的方向"
    软物质是 de Gennes 拿到诺奖的领域，但在国内的关注度远不如凝聚态和高能。

    它的好处是：**实验设备门槛低、理论有统计物理支撑、产业接口广**，而且很多现象肉眼可见，反馈感强。

## 核心内容路径

**基础**
熵驱动的相互作用 → 聚合物物理（高斯链、Flory 理论）→ 胶体与相互作用力（DLVO）→ 液晶 → 表面与界面 → 自组装

**进阶**
流变学（黏弹性）→ 软物质的动力学 → 玻璃化转变与阻塞（jamming）→ 活性物质 → 非平衡软物质

## 教材

| 定位 | 教材 | 说明 |
| --- | --- | --- |
| **入门首选** | de Gennes《Soft Matter》（或《Soft Interfaces》） | 诺奖得主写的小册子，视角极高 |

| 参考 | Israelachvili《Intermolecular and Surface Forces》 | 界面与相互作用力的标准参考 |

## 为什么对自学者友好

- **很多现象可以自己做**（桌面实验：颗粒堆积、泡沫演化、液晶）
- 计算项目相对容易做出视觉效果
- 理论依赖统计物理而非重型数学

## 配套计算项目

- 聚合物的随机行走与自避行走模拟
- 胶体粒子的布朗动力学
- 颗粒物质的堆积与阻塞（jamming）
- 液晶的向列相序参量演化
- 活性物质的集体运动

## 常见坑

- **低估熵的重要性** —— 软物质里大部分"力"其实是熵效应，硬物质训练的直觉在这里会误导你
- 跳过流变学 —— 软物质的定义性特征就是"软"，不会黏弹性等于没入门
- 以为它"简单" —— 看起来日常，理论难度并不低（jamming、玻璃化都是硬问题）
