# 轨道 A　理论物理

> 目标：做出一流的研究，进入顶尖课题组或海外博士项目。

## 适合谁

- 想做研究、想读博、想走学术路径
- 对"为什么"的兴趣大于对"有什么用"的兴趣
- 数学能力强，且**享受**长时间没有反馈的推导

**不适合谁**：

- 主要目标是高薪（见[出路与规划](../出路与规划.md)——纯理论的产业接口最弱）
- 需要频繁的正反馈才能持续推进的人

!!! danger "先说清楚风险"
    全球每年产出的理论物理博士远多于新增教职岗位。走这条路要做好"最终不做学术"的心理准备和技能准备。

    **这不意味着不该走**——只是要走得清醒：
    - 选一个**产业接口好的理论方向**（凝聚态理论、量子信息理论），而不是纯高能/形式理论
    - **始终保持编程能力**，这是你的退路
    - 详见[出路与规划](../出路与规划.md)

## 时间预算

| 阶段 | 内容 | 时长 |
| --- | --- | --- |
| 阶段 1 | 四大力学扎实 | 12–18 个月 |
| 阶段 2 | 数学补强（群论、微分几何、复变） | 与阶段 1 并行 |
| 阶段 3 | QFT + GR | 12 个月+ |
| 阶段 4 | 方向专业课 | 6–12 个月 |

**贯穿全程**：计算物理项目、科研训练。

## 分阶段路径

### 阶段 1：四大力学

这是全部的地基。**必须做到"会算"而不是"学过"**。

- [理论力学](../四大力学/理论力学.md)　Goldstein，重点：拉格朗日/哈密顿形式、诺特定理
- [电动力学](../四大力学/电动力学.md)　Griffiths 做透，第 3 章边值问题是核心
- [量子力学](../四大力学/量子力学.md)　Griffiths → Sakurai，必须做两遍
- [热力学与统计物理](../四大力学/热统.md)　Schroeder → Kardar

**检验**：能解出 [Lim 系列](../习题与解答.md) 中 50% 的题目。

### 阶段 2：数学补强

| 数学 | 为什么 |
| --- | --- |
| [群论](../进阶理论/群论.md) | 现代物理的通用语言，性价比最高 |
| [微分几何](../进阶理论/微分几何与拓扑.md) | GR 与规范场论的基础 |
| [数学物理方法](../数学基础/数学物理方法.md) | 复变、特殊函数、格林函数 |

### 阶段 3：QFT + GR

- [量子场论](../进阶理论/量子场论.md)　**Tong 讲义入门 → Peskin 做习题 → Zee 对照理解**
- [广义相对论](../进阶理论/广义相对论.md)　Carroll

!!! tip "不要两门都学透"
    除非你做量子引力，否则应该**一门深入、一门够用**。做凝聚态理论的，QFT 要深、GR 了解即可；做宇宙学的反之。

### 阶段 4：方向专业课 + 科研

到这一步就该定方向并开始做东西了。见：

- [凝聚态](凝聚态.md)（理论与计算的产业接口最好）
- [AMO 与量子信息](AMO.md)
- [高能天体](高能天体.md)

同时开始[科研训练](../科研训练.md)。

## 检验标准

| 阶段 | 过关标志 |
| --- | --- |
| 四大力学 | Lim 系列解出 50% |
| QFT | 能独立算出几个费曼图振幅；能推导 Propagator |
| GR | 能独立推导 Schwarzschild 解 |
| 进入科研 | 能复现一篇论文；能提出自己的小问题 |

## 出口

- 海外顶尖 PhD 项目
- 国内顶尖组直博
- 国家实验室、研究所

## 常见坑

- **跳过四大力学直接上 QFT** —— 必崩，没有例外
- **只看不推** —— 理论物理的推导极长，看一遍以为懂了是错觉
- **不做题** —— [习题与解答](../习题与解答.md)里那些资格考试题就是为这一层设计的
- **不碰编程** —— 哪怕做纯理论，会写代码的物理学家选择多得多
- **过早锁定窄方向** —— 在真正接触之前锁定方向，往往是因为看了科普而不是因为了解
- **不进组** —— 自学科研有上限，见[科研训练](../科研训练.md)
