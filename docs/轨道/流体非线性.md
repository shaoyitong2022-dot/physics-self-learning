# 轨道 G　流体与非线性物理

## 轨道信息

| | |
|---|---|
| **适合谁** | 对非线性、湍流、斑图形成、复杂系统感兴趣；数学（尤其 PDE）能力强 |
| **不适合谁** | 希望快速产出的人（这个领域进展慢、问题硬） |
| **起点要求** | 理论力学 + 偏微分方程 + 非线性动力学 |
| **时间预算** | 12–18 个月 |
| **出口** | 流体/非线性课题组；工程领域（CFD、航空、气象、能源） |
| **产业接口** | ★★★☆☆ 中等，靠 PDE 与建模能力迁移 |

**特点**：经典但极难，且与工程、气象、海洋、天体物理交叉极广。**湍流是物理学中著名的未解问题。**

## 需要先具备

| 项目 | 要求 |
| --- | --- |

## 核心内容路径

**流体力学**
流体描述（欧拉/拉格朗日）→ Navier–Stokes 方程 → 无粘流与涡量 → 边界层 → 稳定性与转捩 → 湍流（Kolmogorov 理论）→ 对流与不稳定性 → 磁流体力学（MHD）

**非线性物理**
非线性振子 → 分岔与混沌 → 孤子与可积系统 → 反应扩散与图灵不稳定性 → 斑图形成 → 湍流的动力学系统视角

## 教材

| 层次 | 教材 | 说明 |
| --- | --- | --- |
| 流体（首选） | Landau《流体力学》（卷 6） | 薄而深刻，物理直觉极强 |
| 流体（标准） | Batchelor《An Introduction to Fluid Dynamics》 | 经典标准教材 |
| 流体（现代） | Kundu & Cohen《Fluid Mechanics》 | 覆盖面广，适合工程向 |
| 非线性 | Strogatz《Nonlinear Dynamics and Chaos》 | **极佳的入门**，讲得非常好，强烈推荐 |
| 孤子 | Drazin & Johnson《Solitons: An Introduction》 | 简明 |
| 湍流 | Frisch《Turbulence》 | 经典但偏难 |
| 斑图 | Cross & Greenside《Pattern Formation and Dynamics in Nonequilibrium Systems》 | — |

!!! tip "从 Strogatz 开始"
    非线性动力学这一块，**Strogatz 的书是近年来少有的"写得极好"的教材**。它把混沌、分岔、分形讲得既清楚又有趣，是进入整个领域的最佳入口。

## 配套计算项目

- 洛伦兹吸引子与分岔图
- KdV 方程的孤子解与碰撞
- Rayleigh–Bénard 对流的数值模拟
- 格子玻尔兹曼方法模拟流动
- 反应扩散方程的图灵斑图

## 常见坑

- **低估非线性**。线性直觉在这里几乎全部失效，"小扰动变大"是常态。
- **跳过 Strogatz 直接上湍流** —— 而没有非线性动力学基础，湍流完全无法理解。
- 只做解析不做数值 —— 这个领域的可视化（涡量场、斑图）是理解的关键。
