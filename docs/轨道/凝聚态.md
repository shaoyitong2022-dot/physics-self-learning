# 轨道 B　凝聚态与材料

!!! tip "这是综合最优的一条方向轨道"
    如果你还没确定方向，**默认选它**。凝聚态既有世界级的科研前沿（超导、拓扑物态、量子材料），又有最宽的产业出口（半导体、量子计算、材料）。见[出路与规划](../出路与规划.md)。

## 轨道信息

| | |
|---|---|
| **适合谁** | 对固体、超导、拓扑、量子材料感兴趣；想要"进可做顶尖科研、退可进产业"的选项 |
| **不适合谁** | 只想做纯形式理论、对实验与材料毫无兴趣的人 |
| **起点要求** | 四大力学（量子力学与统计物理尤其要扎实） |
| **时间预算** | 四大力学之后，约 12–18 个月到能进组干活 |
| **出口** | 凝聚态课题组（国内顶尖组极多）/ 半导体、量子计算、材料产业 |
| **产业接口** | ★★★★★ 最好的一条 |

**特点**：物理学中最大的分支，从业者最多，与材料、器件的联系最紧密。对自学者相对友好 —— 很多问题可以用数值方法直接验证。

## 需要先具备

| 项目 | 要求 |
| --- | --- |
| 物理 | 四大力学，**尤其量子力学与统计物理要扎实** |
| 数学 | 线性代数、群论（对称性）、偏微分方程 |

## 核心内容路径

**第一层　固体物理基础**
晶体结构与倒格子 → 晶格振动与声子 → 能带理论 → 电子输运（Drude、Boltzmann）→ 半导体

**第二层　多体与相变**
二次量子化 → 相互作用电子气 → 平均场与 Landau 相变理论 → 超导（BCS）→ 磁性 → 强关联初步

**第三层　现代专题**
拓扑物态（Berry 相位、陈数、拓扑绝缘体）→ 量子霍尔效应 → 重整化群 → 量子相变 → 低维系统 → 非平衡与开放系统

## 教材

| 层次 | 教材 | 说明 |
| --- | --- | --- |
| 基础 | Ashcroft & Mermin《Solid State Physics》 | 公认标准的固体物理教材，厚但清楚 |
| 基础（更现代） | Simon《The Oxford Solid State Basics》 | 薄而现代，适合快速入门 |
| 现代视角 | Altland & Simons《Condensed Matter Field Theory》 | 用场论语言讲凝聚态，研究生标准 |
| 高等 | Marder《Condensed Matter Physics》 | 覆盖面广 |
| 强关联 | Coleman《Introduction to Many-Body Physics》 | 现代、清楚 |
| 拓扑 | Bernevig《Topological Insulators and Topological Superconductors》 | 拓扑物态标准参考 |
| 中文 | 黄昆《固体物理学》 | 中文经典，薄而精炼 |

## 为什么对自学者友好

- **可计算**：紧束缚模型、Hubbard 模型、Ising 模型都能在个人电脑上跑
- **有直觉**：很多现象可以画图、可视化
- **资源丰富**：教材与讲义极多

## 配套计算项目

- 紧束缚模型能带结构计算
- Ising 模型与临界指数
- 一维 Hubbard 模型的精确对角化
- Berry 相位与陈数的数值计算
- 重整化群（一维 Ising 实空间 RG）

见[项目清单](../计算物理/项目清单.md)。

## 常见坑

- **只学固体物理不学多体理论** —— 那就停留在 20 世纪中叶的水平
- **跳过二次量子化** —— 现代凝聚态文献全在用这套语言
- 不做数值项目 —— 凝聚态的很多直觉（如能带、相变）必须靠算出来才能建立
