# 轨道

本书按**轨道**组织。每条轨道是一条完整路径：从你现在的位置，到你想要的出口，中间该读什么、做什么、怎么检验，全部列清楚。

## 全部轨道

!!! tip "方向不确定时的默认选择"
    在[出路与规划](../出路与规划.md)里按"产业接口 × 技能可迁移性"打过分——**凝聚态（B）、AMO（D）、量子信息（D2）、计算（E）**四条的交集最大：既有一流科研前沿，又有蓬勃的产业需求。

    如果你完全没想法，从这四条里挑。

## 先选哪条？

!!! tip "在四大力学学扎实之前，别急着选方向"
    大一大二的同学直接走**轨道 0**。在你把四大力学真正啃下来之前，方向选择基本靠想象——你还没见过那些方向真正长什么样，谈喜欢没有依据。

    等到大三、四大力学基本过完之后，再回来选一条方向轨道。

## 轨道不是互斥的

- 轨道 0 是**所有人**的底子，其他轨道都建立在它之上
- 轨道 A（理论物理）与 B/C/D/G 是"深度 vs 方向"的关系：A 更偏方法论的深度，B–G 是具体领域
- 轨道 E（计算）可以**并行**于任何一条，它提供的是技能而非方向
- 轨道 F（考研）是阶段性的，考完就结束

**推荐组合**：轨道 0 → 轨道 A 或 B/C/D → 全程穿插轨道 E 的计算项目。

## 每条轨道页的结构

每条轨道页都会给出：

1. **适合谁 / 不适合谁**（诚实地说清楚）
2. **时间预算**（总时长与每周分配）
3. **分阶段路径**（每个阶段读什么、做什么）
4. **检验标准**（怎么知道自己过关了）
5. **出口**（走完之后你能做什么）
6. **常见坑**（这条路上的人通常栽在哪）
