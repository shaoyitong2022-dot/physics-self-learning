# 轨道 J　等离子体与核物理

两个相关性不强但常放在一起的方向，因为它们的产业/应用出口相似（能源）。

## 等离子体物理

| | |
|---|---|
| **适合谁** | 对磁约束聚变、空间物理、天体等离子体感兴趣 |
| **起点要求** | 电动力学 + 流体力学 + 统计物理 |
| **出口** | 聚变研究（ITER、国内聚变堆计划）、航天、半导体工艺（等离子体刻蚀） |
| **产业接口** | ★★★★☆ **聚变领域近年投资爆发**，人才需求大 |

!!! note "聚变正在变热"
    过去二十年等离子体是"冷门"，但近年来可控聚变的商业投资大幅增长（CFS、Helion、TAE 等，国内也有多个项目）。

    这意味着：**这个方向的就业市场比十年前好得多。**

### 核心内容

单粒子运动（回旋、漂移）→ 动理学（Vlasov 方程、朗道阻尼）→ 磁流体力学（MHD）→ 等离子体波 → 不稳定性 → 输运与约束 → 磁约束（托卡马克、仿星器）与惯性约束

### 教材

| 定位 | 教材 |
| --- | --- |
| 入门 | Chen《Introduction to Plasma Physics and Controlled Fusion》—— 公认最好的入门 |
| 标准 | Goldston & Rutherford《Introduction to Plasma Physics》 |
| 进阶 | Stix《Waves in Plasmas》；Freidberg《Plasma Physics and Fusion Energy》 |

### 配套计算项目

- 单粒子在电磁场中的回旋运动与漂移
- Vlasov–Poisson 的粒子云（PIC）模拟
- 朗道阻尼的数值验证
- 磁面与托卡马克平衡

## 核物理

| | |
|---|---|
| **适合谁** | 对原子核结构、核反应、核天体物理、核技术感兴趣 |
| **起点要求** | 量子力学（含散射）+ 统计物理 |
| **出口** | 核物理研究所、核能产业、医学物理（放疗）、核技术 |
| **产业接口** | ★★★☆☆ 核电与医学物理是稳定出口 |

### 核心内容

核的基本性质 → 核模型（液滴模型、壳模型）→ 核衰变 → 核反应 → 核力与核子相互作用 → 核天体物理（核合成）→ 应用（反应堆物理、辐射防护）

### 教材

| 定位 | 教材 |
| --- | --- |
| 标准 | Krane《Introductory Nuclear Physics》—— 公认标准入门 |
| 现代 | Bertulani《Nuclear Physics in a Nutshell》—— 更现代、更紧凑 |
| 中文 | 卢希庭《原子核物理》 |

### 常见坑

- 这两个方向的**数学负担相对轻**，但对实验与工程的了解要求高
- 核物理的"纯理论"岗位少，应用出口（核电、医学物理）反而更稳
- 等离子体容易低估 MHD 的难度——它是流体与电动力学的叠加，两者都要会
