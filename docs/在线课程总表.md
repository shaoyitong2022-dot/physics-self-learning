# 在线课程总表

!!! tip "这一页是干什么用的"
    本书每个模块都该配一门**有含金量的线上课**。这一页把它们集中列出来，方便你按图索骥。

    **所有链接都经过可访问性验证**（2026-09 核验，HTTP 200）。如果你发现哪个打不开，请提 issue —— 链接腐烂是这类项目的头号死因。

    唯一的例外是 Feynman 讲义站点，它对脚本访问返回 403（反爬），但浏览器打开正常。

## 先说怎么用这些课

**大部分资源来自 MIT OpenCourseWare（OCW）。**它好在哪：

- 免费、无需注册、永久存档
- 多数课程带完整讲义、作业（problem sets）、考试题，**相当一部分带答案**
- 它是目前唯一一个"课程结构完整到足以自学"的开放平台

**但也有坑，先说清楚**：

| OCW 的局限 | 应对 |
| --- | --- |
| 老课程的录像质量参差（有些只有音频或课堂笔记） | 优先选带 "SC"（Scholar 版）或有视频图标的课程 |
| 不是每门课都有作业答案 | 配合本书的[习题与解答](习题与解答.md)用 |
| 讲得快，默认你有对应的数学基础 | 卡住时查[数学贯穿线](学习规划.md) |

!!! warning "不要同时上三门课"
    最常见的问题是贪多。**一次只跟一门课**，把它的问题集做完，再开下一门。收藏夹里躺着五门没看完的课，等于零。

## 关于"含金量"的判断标准

选课时的几个判据，按重要性排序：

1. **有没有作业（problem sets）**——没有作业的课程，看完等于没看
2. **作业有没有答案**——决定你能不能自学（这也是本书[习题与解答](习题与解答.md)存在的理由）
3. **录像是否完整**——只有讲义的课程，对自学者门槛高很多
4. **是否对应一本公认教材**——能配教材的课，学起来顺畅得多

!!! warning "警惕两类课程"
    - 只有概念讲解、没有计算的"科普型"课程。看得爽，学不到。
    - 打包出售的"速成"网课。物理没有速成。
