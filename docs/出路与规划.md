# 出路与规划：把路看清楚再走

!!! warning "这一页讲的是现实，不是理想"
    下面关于出路与薪酬的判断是结构性的，会尽量诚实。**具体薪酬数字时效性强、地域差异大，请自行核实最新市场数据**——但哪些方向天花板高、哪些方向岗位稀缺，这些结构性判断是稳定的。

## 一、先看清物理专业的出口

物理专业最大的特点是：**它训练的能力很值钱，但"物理学本身"的岗位很少。**

| 出口 | 典型去向 | 薪酬量级 | 时间成本 | 风险 |
| --- | --- | --- | --- | --- |
| **学术界教职** | 高校、研究所 | 早期低，稳定后中等 | 最长（本科+博士+博后 ≈ 10–15 年） | **极高**，教职岗位远少于博士产出 |
| **量化金融** | Citadel、Jane Street、Two Sigma、国内头部私募 | **最高档** | 硕士/博士即可 | 中，行业周期性强但物理背景极吃香 |
| **AI / 机器学习** | 大厂研究院、AI 创业公司 | **最高档** | 硕士/博士 | 中低，岗位极多，技能可迁移 |
| **半导体 / 芯片** | 台积电、ASML、Intel、国内芯片厂 | 中高档（国内近年涨幅大） | 硕士即可 | 低，产业刚需 |
| **量子计算** | IBM、Google、IonQ、本源量子等 | 中高档 | 博士为主 | 中，行业还在早期 |
| **数据科学 / 算法** | 互联网、金融、咨询 | 中高档 | 硕士即可 | 低 |
| **转行（金融/咨询/公务员）** | 投行、MBB、体制内 | 差异极大 | 本科即可 | 低 |
| **中学教育** | 重点中学、教育机构 | 中等，稳定 | 本科/硕士 | 低 |

!!! danger "一个必须直面的事实"
    **纯理论方向（高能、弦论、形式理论）的学术岗位极少**，全球每年新增教职数量远小于博士生毕业数量。如果目标是"高薪"，走纯理论是**概率最低**的一条路。

    这话不好听，但如果不提前说清楚，很多人会在博士第五年才发现。

## 二、核心策略：进可攻，退可守

最优解不是"选学术"或"选工业界"，而是**选一个两条路都走得通的方向**。

判断标准有两个：

1. **产业接口**：这个方向有没有对应的产业？（有 → 退路好）
2. **技能可迁移**：训练出来的能力能不能卖到别处？（能 → 退路好）

按这两条打分：

| 方向 | 产业接口 | 技能可迁移性 | 综合评价 |
| --- | --- | --- | --- |
| **凝聚态（实验/计算/量子材料）** | ★★★ 半导体、量子计算、材料 | ★★★ 编程、建模、数据处理 | **最优**：进可做顶尖科研，退可进芯片/量子产业 |
| **AMO / 量子信息** | ★★★ 量子计算产业正热 | ★★★ 编程、控制、信息处理 | **极优**：当下最热的交叉点 |
| **计算物理 / 科学机器学习** | ★★★ 直接通向 AI 与量化 | ★★★★ 几乎全部可迁移 | **最优**：退路最宽 |
| **天体 / 宇宙学** | ★ 弱 | ★★ 数据分析能力可迁移 | 学术导向强，退路靠数据技能 |
| **高能理论 / 弦论** | ☆ 几乎没有 | ★★ 数学与建模能力可迁移 | **退路最窄**，靠个人能力硬转 |
| **流体 / 非线性** | ★★ 航空、气象、能源 | ★★ PDE 与建模 | 中等 |

!!! tip "一句话结论"
    想同时拿到"顶尖学术路径"和"高薪退路"，**凝聚态 / AMO·量子信息 / 计算物理**这三个方向是交集最大的。它们既有一流的科研前沿，又有蓬勃的产业需求。

## 三、真正的硬通货：三种可迁移能力

无论走哪条路，以下三种能力决定你的上限。它们**和具体方向无关**，是物理训练真正值钱的部分：

| 能力 | 为什么值钱 | 怎么练 |
| --- | --- | --- |
| **建模能力** | 把 messy 的现实问题抽象成可解的方程——这是 quant、AI 研究员、算法工程师的核心能力 | 做难题，尤其是没有标准解法的题 |
| **编程与数值能力** | 能把想法实现出来并验证 | [计算物理项目](计算物理/项目清单.md) 至少 10 个 |
| **读文献与快速学习能力** | 进入陌生领域能迅速上手 | 见[科研训练](科研训练.md) |

!!! note "反过来说"
    如果你的训练只停留在"会做教材习题"，那这三种能力一个都没练到。**这也是很多人读完博士却发现工业界不要的原因**——不是物理没用，是训练方式不对。

## 四、推荐的路径组合

```
大一大二   把基础砸实（GPA + 四大力学 + 编程）
              ↓
大三       确定方向（凝聚态/AMO/计算 三选一）+ 进组做科研 + 做计算项目
              ↓
大三暑假   暑期科研（国内课题组 或 海外 REU/暑研）  ← 关键节点
              ↓
大四       申请：保研 / 直博 / 海外 PhD
              ↓
硕博期间   科研产出 + 保持产业可迁移技能（编程、ML）
              ↓
出口       学术（教职/国家实验室） 或 产业（量化/AI/芯片/量子计算）
```

**关键节点是大三暑假的科研经历。** 无论保研还是出国，这一段经历和它带来的推荐信，权重远高于考试成绩。

## 五、给不同目标的具体建议

| 你的目标 | 方向建议 | 重点投入 |
| --- | --- | --- |
| **想做顶尖学术** | 凝聚态 / AMO / 计算（避开纯理论的红海） | 科研经历 > GPA > 英语 |
| **想高薪，学术作为备选** | 计算物理 + ML | 编程能力 + 实习 |
| **想尽快变现** | 量化 / AI | 硕士即可，重点刷题 + 实习 + 项目 |
| **还没想好** | 先按"计算 + 凝聚态"走 | 这两条路的退路最宽，不会选错 |

## 六、不要做的事

- **不要为了"纯粹"选高能理论**，除非你非常清楚教职市场的竞争烈度且愿意承担风险
- **不要完全放弃编程**。哪怕做纯理论，会写代码的物理学家选择多得多
- **不要用"我还不确定方向"拖延**。在信息不足时，选退路最宽的那个方向，这是理性决策，不是妥协
- **不要等到大四才准备升学**。见[升学路径](升学路径.md)的时间线
