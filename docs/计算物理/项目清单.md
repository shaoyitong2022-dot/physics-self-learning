# 计算物理项目清单

!!! tip "为什么这一页很重要"
    物理自学缺实验、缺判卷。计算项目是唯一能同时补上这两件事的东西：**代码跑错了会报错**（反馈），**跑出来的图可以展示**（成果）。一个能跑出正确氢原子能级的代码，比读完三章教材更能证明你真的学会了。

**通用要求**：每个项目都用 Jupyter Notebook 或独立 Python 脚本实现，写清物理模型、数值方法、结果检验方式，存进你自己的 GitHub 仓库。这就是你的作品集。

## 入门级（对应普通物理）

| # | 项目 | 涉及的物理 | 数值方法 |
| --- | --- | --- | --- |
| 1 | 抛体运动与空气阻力 | 牛顿力学、阻力模型 | 常微分方程初值问题 |
| 2 | 单摆的大角度周期 | 非线性振动 | 数值积分 + 与解析解对比 |
| 3 | 行星轨道与开普勒定律 | 万有引力、能量守恒 | 辛积分器（Verlet / leapfrog） |
| 4 | 三体问题与混沌 | 混沌、初值敏感性 | 高精度积分器，对比 RK4 与辛积分的能量漂移 |
| 5 | 洛伦兹吸引子 | 非线性动力学 | 相图、庞加莱截面 |
| 6 | 电荷分布的电场线图 | 静电场 | 有限差分 / 直接求和 |

!!! note "第 3、4 题的关键"
    一定要对比 **RK4 与辛积分器**的长期能量守恒表现。这一个对比能让你真正理解"数值方法不是中立的"——这是计算物理最重要的第一课。

## 常见坑

- **把代码写成一次性脚本**。每个项目都应该是可复现的 Notebook，有说明、有检验。
- **不做收敛性检验**。网格加密一倍、步长减半，结果应该按理论阶数收敛。这是判断代码对不对的唯一硬标准。
- **不用现成库**。第 1–6 题可以手写积分器练手，第 7 题之后应该直接用 `scipy.linalg.eigh` 这类成熟实现。
- **跳过了量纲检验**。数值结果必须做量纲和数量级检查，这是物理工作者区别于程序员的地方。
