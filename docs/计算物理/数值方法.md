# 数值方法

按物理课的实际需要组织，而不是按数学分类。每个方法都标注了"什么时候你会第一次需要它"。

## 基础

| 方法 | 第一次需要它 |
| --- | --- |
| 求根（二分、牛顿） | 打靶法解薛定谔方程 |
| 数值积分（梯形、辛普森、高斯求积） | 计算积分形式的物理量 |
| 有限差分 | 导数与拉普拉斯算符的离散化 |
| 插值与拟合 | 处理实验数据 |

## 常微分方程

| 方法 | 说明 |
| --- | --- |
| 欧拉法 | 教学用，实际不要用 |
| **RK4** | 通用主力，精度与成本平衡好 |
| **辛积分器（Verlet / leapfrog）** | **做轨道与分子动力学必须用这个**。RK4 长时间积分会能量漂移，辛积分器不会 |
| 自适应步长（RK45 / Dormand–Prince） | `scipy.integrate.solve_ivp` 默认，适合非保守系统 |
| 刚性问题求解（BDF、Radau） | 含时演化、化学反应动力学 |

!!! warning "最重要的一条"
    做**保守系统**（轨道、分子动力学）的长时间积分，必须用辛积分器。用 RK4 跑一百万步，能量会漂移到荒谬的程度。这一个认识是计算物理的第一课。

## 偏微分方程

| 方法 | 应用 |
| --- | --- |
| 有限差分（显式） | 波动方程、扩散方程 |
| **Crank–Nicolson** | 含时薛定谔方程（隐式、保概率） |
| 松弛法（Jacobi / Gauss–Seidel / SOR） | 泊松方程的边值问题 |
| 有限元（FEM） | 复杂几何，用 FEniCS / Firedrake |
| 谱方法 | 高精度、周期边界 |

## 线性代数

| 方法 | 应用 |
| --- | --- |
| `scipy.linalg.eigh` | 哈密顿量对角化（量子力学核心） |
| 稀疏矩阵（`scipy.sparse`） | 大网格上的 PDE |
| 奇异值分解 | 数据降维、张量网络 |
| 广义本征值 | 多自由度小振动 |

## 蒙特卡洛

| 方法 | 应用 |
| --- | --- |
| 随机数生成（注意用高质量生成器） | 全部 |
| Metropolis–Hastings | Ising 模型、路径积分 |
| 重要性采样 | 高维积分 |
| MCMC 参数估计（`emcee`） | 误差分析 |

## 信号处理

| 方法 | 应用 |
| --- | --- |
| FFT | 谱分析、快速卷积、格点计算 |
| 滤波与窗函数 | 实验数据处理 |
| 功率谱估计 | 涨落、噪声分析 |

## 通用纪律

1. **收敛性检验**：改变分辨率，看误差是否按预期阶数下降
2. **守恒量检验**：能量、动量、概率是否守恒
3. **解析极限对比**：先跑一个已知解析解的例子
4. **量纲检查**：数值结果必须做量纲和数量级检验
