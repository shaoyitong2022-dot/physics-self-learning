# 群论与对称性

**地位**：现代物理的通用语言。量子力学、QFT、粒子物理、凝聚态、晶体学都在用它。

**典型耗时**：每周 10 小时，约 2–3 个月

!!! tip "性价比极高的一门"
    投入 2–3 个月学群论，能让后面 QFT、粒子物理、凝聚态的学习速度提升一大截。它是那种"早学早受益"的工具课。

## 核心内容

群的基本概念 → 有限群与表示论 → 李群与李代数 → SU(2) 与角动量 → SU(3) 与夸克模型 → 置换群与全同粒子 → 晶体点群与空间群 → 不可约表示与特征标 → 杨图（进阶）

## 学习建议

1. **从 SU(2) 入手**。如果你已经学过量子力学的角动量，那么 SU(2) 的表示论就是把已知内容换个说法，是最佳的切入点。
2. **不要陷入纯数学的严格性**。物理学需要的群论是"会用"，不是"会证"。
3. **和物理课绑定学**。学 QFT 的规范场时同步学李代数表示，效果远好于单独先学。

## 检验标准

- [ ] 能用升降算符推导 SU(2) 的全部不可约表示
- [ ] 知道为什么自旋 1/2、1、3/2 对应不同的表示维数
- [ ] 能说出 SU(3) 的 $3 \otimes \bar{3} = 1 \oplus 8$ 的物理含义（介子八重态）
- [ ] 会用特征标表判断一个表示是否可约
