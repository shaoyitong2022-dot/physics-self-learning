# 广义相对论

**地位**：引力的现代理论，宇宙学与天体物理的基础。也是物理学中数学结构最美的一门。

**典型耗时**：每周 10 小时，约 4–6 个月

## 先修要求

| 项目 | 要求 |
| --- | --- |
| 物理 | 狭义相对论（必须熟练）、理论力学（拉格朗日形式）、电动力学的张量写法 |
| 数学 | **微分几何**（流形、张量、协变导数、曲率）—— 可与 GR 同步学 |

!!! note "可以和微分几何同步学"
    不需要先把微分几何学完再学 GR。推荐用 [Carroll](https://en.wikipedia.org/wiki/SpaceTime_and_Geometry) 这类教材，它前几章自带所需的几何。

## 核心内容

等价原理 → 流形与张量 → 协变导数与联络 → 测地线 → 曲率与黎曼张量 → 爱因斯坦场方程 → Schwarzschild 解 → 黑洞 → 引力波 → 宇宙学（FLRW 度规）→ 实验检验

## 教材

| 定位 | 教材 | 说明 |
| --- | --- | --- |
| **首选** | Carroll《Spacetime and Geometry》 | 现代标准入门教材，讲得清楚且自带所需几何 |
| 更平缓 | Schutz《A First Course in General Relativity》 | 进度更慢，适合数学准备不足的人 |
| 进阶 | Wald《General Relativity》 | 严格、现代，适合第二遍 |
| 经典 | Misner, Thorne & Wheeler《Gravitation》（MTW） | 大部头，百科式，参考性质 |
| 参考 | Landau《场论》卷 2 | 与狭义相对论统一处理，视角高 |

## 配套习题

- Carroll 习题（难度适中，必须做）
- Schutz 习题（更基础）
- [Lim 系列](../习题与解答.md)中相关部分

## 配套计算项目

- 光线在 Schwarzschild 度规中的偏折
- 测地线数值积分（水星近日点进动）
- 引力波的波形绘制

## 常见坑

- **张量指标操作不熟练**。这一点会拖慢全部进度，建议早期专门练指标运算。
- **只看科普**。黑洞、引力波的科普很多，但它们完全不能替代计算训练。
- **跳过 Schwarzschild 解**。这是唯一能完整手算的非平凡解，必须亲自推一遍。
