# 微分几何与拓扑

**地位**：[广义相对论](广义相对论.md)的数学基础，也是现代凝聚态（拓扑物态）、规范场论的必备工具。

**典型耗时**：每周 10 小时，约 3–4 个月

!!! note "拓扑在当代物理中的地位上升极快"
    拓扑绝缘体、拓扑序、陈数、Berry 相位 —— 2016 年诺贝尔物理奖就是颁给拓扑相变。这块从"纯数学"变成了凝聚态研究者的日常工具。

## 核心内容

**微分几何**：流形 → 切空间与余切空间 → 张量场 → 外代数与微分形式 → 联络与协变导数 → 曲率 → 测地线 → 李导数与 Killing 向量 → 纤维丛与规范场

**拓扑**：基本群与同伦 → 同调论 → 流形分类 → 陈类与指标定理（进阶）→ Berry 相位与拓扑不变量（物理应用）

## 教材

| 定位 | 教材 | 说明 |
| --- | --- | --- |
| **首选** | Tu《An Introduction to Manifolds》 | 现代、清楚，适合物理学生 |
| 经典 | do Carmo《Riemannian Geometry》 | 黎曼几何标准教材 |
| 物理向 | Frankel《The Geometry of Physics》 | 专为物理学家写，覆盖面广，可作参考 |
| GR 配套 | Carroll《Spacetime and Geometry》前几章 | 如果只为 GR，这几章够了 |
| 拓扑物理 | Bernevig《Topological Insulators and Topological Superconductors》 | 直接讲物理应用 |

## 学习建议

1. **目标导向**。如果只为了 GR，Carroll 前几章足够，不要去啃 Tu 全书。
2. **微分形式值得单独学**。外代数与微分形式在电动力学（把 Maxwell 方程写成 $dF=0, d*F=J$）和 GR 里都能极大化简。
3. **拓扑部分按需学**。做凝聚态拓扑物态的，重点是 Berry 相位与陈数，不是同调论。

## 检验标准

- [ ] 能把麦克斯韦方程组写成微分形式
- [ ] 能计算一个简单度规的克里斯托弗符号与里奇张量
- [ ] 理解 Berry 相位与几何相位的联系
