# 量子场论

**地位**：现代理论物理的核心语言。高能、凝聚态（多体场论）、宇宙学都要用。

**典型耗时**：每周 10 小时，约 6–12 个月（这是一门会反复重学的课）

## 先修要求

| 项目 | 要求 |
| --- | --- |
| 物理 | 四大力学全部扎实，尤其量子力学（到散射与二次量子化）、狭义相对论 |
| 数学 | 复变（留数定理）、傅里叶变换、群表示论、泛函积分初步 |
| 计算 | 会做符号推导验证（SymPy / Mathematica） |

## 核心内容

经典场论与拉格朗日场论 → 诺特定理与对称守恒 → 正则量子化 → 标量场 → 狄拉克场 → 电磁场量子化 → 费曼图与微扰论 → 散射截面与 S 矩阵 → 重整化 → 规范场论 → 自发对称破缺与 Higgs → 标准模型

## 教材

| 定位 | 教材 | 说明 |
| --- | --- | --- |
| **入门首选** | **David Tong 的讲义**（免费 PDF） | 极佳入门，行文清楚，强烈推荐作为第一本 |
| 标准 | Peskin & Schroeder《An Introduction to Quantum Field Theory》 | 公认标准教材，习题极有价值但偏难 |
| 视角型 | Zee《Quantum Field Theory in a Nutshell》 | 直觉优先，讲"为什么"，适合做第二本 |
| 参考 | Weinberg《The Quantum Theory of Fields》 | 权威但极难，参考性质 |
| 中文 | 可选译本若干 | — |

!!! tip "推荐组合"
    **Tong 讲义入门 → Peskin 做习题 → Zee 对照理解**。这三本的搭配覆盖了"会算""能做""能懂"三个层面。

## 配套习题

- Tong 讲义自带习题（难度友好，先做这些）
- Peskin 习题（第 4、5 章的费曼图计算必须做）
- Srednicki《Quantum Field Theory》　以习题驱动，可作为练习册

## 常见坑

- **没学好量子力学就上 QFT**。二次量子化、散射理论不过关，这里一步都走不动。
- **沉迷重整化的哲学讨论**。第一遍先学会算，理解它的深意要等到第二遍。
- **不做费曼图计算**。看懂图和自己算出振幅是两回事，必须动手算至少 20 个图。
- **只看不推**。QFT 的推导极长，看一遍以为懂了是错觉，必须自己推。
