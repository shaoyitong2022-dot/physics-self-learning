# 进阶理论

**前提**：四大力学扎实完成后再进入这一层。提前进入的失败率极高 —— 这一层的每门课都默认你已经能熟练使用四大力学的全部工具。

**典型耗时**：每门 4–6 个月

## 页面

- [量子场论](量子场论.md)
- [广义相对论](广义相对论.md)
- [群论与对称性](群论.md)
- [微分几何与拓扑](微分几何.md)

## 建议顺序

| 情况 | 建议 |
| --- | --- |
| 想做高能 / 粒子 | 群论 → QFT →（GR 选学） |
| 想做引力 / 宇宙学 | 微分几何 → GR →（QFT 选学） |
| 想做凝聚态 | 群论 → QFT（多体场论视角）→ 固体理论 |
| 不确定 | 先学群论。它是所有方向通用的语言 |

!!! note "群论和微分几何是"元工具""
    它们本身不是物理，但现代物理的每个分支都在用。这两门补上之后，读论文的速度会有质变。

## 这一层的特点

和前面所有阶段都不同：**到了这一层，教材的权威性差异极大，且没有公认的"标准路径"**。建议多备几本教材，同一主题对照着读，比死啃一本有效得多。

另外，**及时开始读论文**。到了这个阶段，教材和前沿之间的距离已经很近了，读论文的成本大幅下降（见[文献检索](../工具箱/文献检索.md)）。
