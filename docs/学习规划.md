# 一个仅供参考的物理学习规划

这是按国内物理系典型学制排的一份完整规划。它不假设你从零开始，而是假设你**正在读物理系，想在课内之外把这套东西真正学扎实**。

具体怎么走，取决于你的目标——见[轨道](轨道/index.md)。

## 数学与物理的对应表（贯穿线）

**前提：数学是贯穿线，不是前置课。**不要试图"先把数学学完再学物理"——那样你会在实分析里耗死。正确做法是数学永远领先物理**半步**。

| 学到这里 | 必须已经会用的数学 | 建议同步补的数学 |
| --- | --- | --- |
| 普通物理 · 力学 | 一元微积分、矢量 | 多元微积分 |
| 普通物理 · 电磁学 | 多元微积分、线积分/面积分 | 矢量分析（梯度/散度/旋度） |
| 四大力学 · 理论力学 | 常微分方程、变分法初步 | 拉格朗日乘子、变分法 |
| 四大力学 · 电动力学 | 偏微分方程、分离变量法 | 特殊函数（勒让德、贝塞尔） |
| 四大力学 · 量子力学 | 线性代数（含内积空间、本征值） | 希尔伯特空间、狄拉克符号 |
| 四大力学 · 热统 | 概率论、组合数学 | 鞍点法 |
| 进阶 · 量子场论 | 复变函数（留数定理）、傅里叶变换 | 群表示论 |
| 进阶 · 广义相对论 | 微分几何（流形、张量） | 协变导数、曲率 |

!!! tip "数学跟不上时的处理原则"
    遇到数学卡壳，**不要回头从头重学数学**。找一本"用中学"的书（推荐 Boas《Mathematical Methods in the Physical Sciences》），只补当下用到的那一章，然后立刻回到物理。

## 按年级的规划

### 大一

| 学期 | 课内 | 自学这边 |
| --- | --- | --- |
| 上 | 力学、高等数学 | 建立"建模—列方程—求解—检验"的工作流；开始用 LaTeX 记笔记 |
| 下 | 电磁学、线性代数 | **线性代数要学扎实**，这是量子力学的语言；补 Taylor《Classical Mechanics》或 Morin 的题 |

**大一的重点**：把微积分和线性代数练到熟练，把力学习题做到不用想就能列方程。这一年看起来简单，但地基不牢，大三会塌。

### 大二

| 学期 | 课内 | 自学这边 |
| --- | --- | --- |
| 上 | 光学、热学、数学物理方法 | 数学物理方法（Boas / 梁昆淼）要学透，它是后面所有课的钥匙 |
| 下 | 理论力学、电动力学（或电磁学进阶） | 理论力学补 Goldstein；电动力学**直接上 Griffiths**，比多数中文教材讲得清楚 |

**大二的重点**：数学物理方法 + 理论力学 + 电动力学。这一年是分化点——学得扎实的，大三会很顺；糊过去的，量子力学必崩。

### 大三

| 学期 | 课内 | 自学这边 |
| --- | --- | --- |
| 上 | 量子力学、统计物理 | Griffiths 量子力学主攻；统计物理用 Schroeder 打底 |
| 下 | 量子力学（续）、固体物理、计算物理 | 量子力学第二遍（Sakurai / Shankar）；开始做[计算项目](计算物理/项目清单.md) |

**大三的重点**：四大力学收官。这一年结束前应该做完至少 8 个计算项目，并开始接触一个研究方向。

!!! danger "大三下是分水岭"
    保研、出国、考研的准备都在这一年。无论走哪条路，**四大力学的扎实程度**都是最硬的筹码。

### 大四

| 去向 | 重点 |
| --- | --- |
| 保研 / 直博 | 进组做科研，补方向课（见[轨道](轨道/index.md)） |
| 出国 | 补 QFT / GR 等高阶课，做科研，准备 Sub GRE（如需要） |
| 考研 | 见[轨道 F](轨道/考研.md) |
| 就业 / 转行 | 见[轨道 E](轨道/计算AI量化.md) |

## 贯穿全程的两件事

**一、计算物理。**不要等学完了再做，每学完一个板块就用代码实现它。具体项目见[项目清单](计算物理/项目清单.md)。

**二、习题归档。**用 LaTeX 把做过的题记录下来，推到 GitHub。这既是复习材料，也是你能拿出来的东西。

## 关于"卡住了怎么办"

1. **卡在一道题上超过 1 小时**：去看解答，但要写下"卡在哪一步"。这比硬扛高效得多。
2. **整章看不懂**：换教材。同一门课本书至少给 2–3 本备选，就是为了这种情况。
3. **怀疑自己基础不行**：90% 的情况是数学工具缺失，而不是物理直觉不行。回去查贯穿线表格。
4. **长期没有正反馈**：做计算物理项目。跑出一个正确的氢原子能级图，比你读完三章教材更能让你确信自己在进步。
