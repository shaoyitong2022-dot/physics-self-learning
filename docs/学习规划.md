# 学习路线规划

这里给出三条主路线。先说明一个前提：**数学是贯穿线，不是前置课**。不要试图"先把数学学完再学物理"——那样你会在实分析里耗死。正确做法是数学永远领先物理半步。

## 数学与物理的对应关系（贯穿线）

| 学到这里 | 必须已经会用的数学 | 建议同步补的数学 |
| --- | --- | --- |
| 普通物理 · 力学 | 一元微积分、矢量 | 多元微积分 |
| 普通物理 · 电磁学 | 多元微积分、线积分/面积分 | 矢量分析（梯度/散度/旋度） |
| 四大力学 · 理论力学 | 常微分方程、变分法初步 | 拉格朗日乘子、变分法 |
| 四大力学 · 电动力学 | 偏微分方程、分离变量法 | 特殊函数（勒让德、贝塞尔） |
| 四大力学 · 量子力学 | 线性代数（含内积空间、本征值） | 希尔伯特空间、狄拉克符号 |
| 四大力学 · 热统 | 概率论、组合数学 | 配分函数相关的鞍点法 |
| 进阶 · 量子场论 | 复变函数（留数定理）、傅里叶变换 | 群表示论 |
| 进阶 · 广义相对论 | 微分几何（流形、张量） | 协变导数、曲率 |

!!! tip "数学跟不上时的处理原则"
    遇到数学卡壳，**不要回头从头重学数学**。找一本"用中学"的书（推荐 Boas《Mathematical Methods in the Physical Sciences》），只补当下用到的那一章，然后立刻回到物理。

## 路线 A：理论物理向（最完整，也最艰苦）

适合：想读研、想做理论、想把物理学透的人。

**阶段 0　普通物理（约 5–7 个月）**
力学 → 电磁学 → 热学 → 光学 → 近代物理。配套一本习题集（Irodov 或《物理学难题集萃》）从头做到尾。

**阶段 1　四大力学（约 12–18 个月）**
理论力学 → 电动力学 → 量子力学 → 热力学与统计物理。这是核心，**至少要做完两本教材的 70% 习题**。

**阶段 2　数学补强（与阶段 1 并行）**
数学物理方法（复变 + 偏微分方程 + 特殊函数）、群论。

**阶段 3　进阶（约 12 个月+）**
量子场论 + 广义相对论 + 一个方向专业课。

**阶段 4　进入前沿**
开始读 arXiv 论文 → 复现一篇小论文 → 找导师/课题组。

**贯穿全程：计算物理**。每学完一个板块，用代码实现它（见[项目清单](计算物理/项目清单.md)）。

## 路线 B：计算 / 应用物理向（见效最快）

适合：转行、工程背景、想快速产出的人。

- 普通物理（精简，抓力学/电磁学/热学主干）→ 数学预备（线性代数 + 数值方法优先）→ **计算物理优先** → 按需补四大力学中的量子力学与统计物理
- 核心是"用代码学物理"：每学一个方程，就把它解出来
- 产出：GitHub 上的数值实验项目集，可作为作品集

## 路线 C：爱好者 / 通识向（不追求做题）

适合：想把物理学明白、不打算做研究的人。

- Feynman 物理学讲义（在线免费）+ The Theoretical Minimum（Susskind）系列
- 不追求做题量，但要动手做 PhET 仿真、做计算物理小项目
- 想深入某个方向时再回到路线 A 的对应章节

## 关于"卡住了怎么办"

1. **卡在一道题上超过 1 小时**：去看解答，但要写下"卡在哪一步"。这比硬扛高效得多。
2. **整章看不懂**：换教材。同一门课本书至少给 2–3 本备选，就是为了这种情况。
3. **怀疑自己基础不行**：90% 的情况是数学工具缺失，而不是物理直觉不行。回去查贯穿线表格。
4. **长期没有正反馈**：做计算物理项目。跑出一个正确的氢原子能级图，比你读完三章教材更能让你确信自己在进步。
