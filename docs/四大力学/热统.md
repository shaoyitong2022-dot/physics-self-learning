# 热力学与统计物理

**地位**：四大力学里最"独立"的一门 —— 它几乎不依赖前两门，可以并行推进。同时它也是通往凝聚态、量子信息的必经之路。

**典型耗时**：每周 10 小时，约 3–4 个月

## 先修要求

| 项目 | 要求 |
| --- | --- |
| 物理 | 普物热学、量子力学入门（统计部分需要知道能级概念） |
| 数学 | 概率论（**核心**）、**斯特林公式**、多元微积分、鞍点法（进阶） |

## 核心内容

**热力学**：温度与状态方程 → 三大定律 → 热力学势（内能、焓、自由能、吉布斯自由能）→ 麦克斯韦关系 → 相变与相平衡

**统计物理**：微观态与宏观态 → 熵的统计定义 $S = k\ln\Omega$ → 正则系综与配分函数 → 量子统计（费米–狄拉克、玻色–爱因斯坦）→ 理想气体与光子气体 → 相互作用系统与平均场 → 相变与临界现象 → 涨落

!!! note "配分函数是这门课的中心"
    $Z = \sum_i e^{-\beta E_i}$ 一旦求出来，所有热力学量都可以通过求导得到。整门课的技艺，很大程度上就是"怎么算配分函数"。

## 常见坑

- **只学宏观热力学不学统计** —— 那就错过了这门课的全部精华
- **不理解熵为什么是 $k\ln\Omega$** —— 这个关系是整门课的基石，必须搞懂
- **配分函数求导不熟练** —— 建议自己列一张"从 Z 到各热力学量"的对照表反复用
- 不做 Ising 模型项目 —— 相变和临界现象在纯理论里很难真正"看见"
