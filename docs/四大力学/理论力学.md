# 理论力学（分析力学）

**地位**：四大力学的形式基础。它把牛顿力学重述为更普适的变分原理，这套形式会一直用到量子场论。

**典型耗时**：每周 10 小时，约 3–4 个月

## 先修要求

| 项目 | 要求 |
| --- | --- |
| 物理 | 普物力学（扎实）、微积分 |
| 数学 | 常微分方程、**变分法**（可边学边补）、拉格朗日乘子 |

## 核心内容

拉格朗日力学 → 变分原理 → 对称性与守恒律（诺特定理）→ 中心力问题 → 刚体动力学 → 小振动与简正模式 → 哈密顿力学 → 正则变换 → 哈密顿–雅可比理论 → 连续介质初步

!!! note "诺特定理是这门课的灵魂"
    "每一个连续对称性对应一个守恒量" —— 这一条贯穿全部现代物理。学到 QFT 时会发现，规范对称性就是它的直接延伸。

## 教材

| 定位 | 教材 | 说明 |
| --- | --- | --- |
| **过渡首选** | Morin《Introduction to Classical Mechanics》 | 习题极佳且有分层。如果普物力学不够扎实，先用这本过渡 |
| 标准 | Goldstein《Classical Mechanics》 | 研究生标准教材，正则变换与 H–J 理论讲得透 |
| 中文 | 周衍柏《理论力学教程》 | 国内常用 |
| 参考（第二遍） | **Landau《力学》** | 极薄，视角极高，题少而精。建议第二遍读 |
| 参考 | Susskind《Classical Mechanics》（Theoretical Minimum） | 配合 Landau 看 |

## 常见坑

- **只学拉格朗日不学哈密顿**。哈密顿形式才是通往量子力学和统计物理的桥，不能跳过。
- **不理解为什么要用变分原理**。第一遍接受它"能用"即可，理解它的深意要等到学了 QFT 的路径积分。
- **小振动问题做太少**。广义本征值问题在这里第一次出现，后面凝聚态的声子还会再来一次。
