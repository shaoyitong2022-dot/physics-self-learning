# 四大力学

**地位**：物理本科最核心的四门课。走完这一层，你才真正具备物理学本科的核心能力。

**典型耗时**：每周 10 小时，四门合计约 12–18 个月

## 建议顺序

| 顺序 | 课程 | 理由 |
| --- | --- | --- |
| 1 | [理论力学](理论力学.md) | 拉格朗日/哈密顿形式是后面一切的形式基础 |
| 2 | [电动力学](电动力学.md) | 数学最吃重，早点啃掉 |
| 3 | [量子力学](量子力学.md) | 需要线代，且它是后续一切的入口 |
| 4 | [热力学与统计物理](热统.md) | 相对独立，可与 2、3 并行 |

!!! tip "热统可以并行"
    热统对前三门依赖很少，完全可以和电动力学或量子力学同时推进。这样安排能把总时间压下来。

## 通用建议

1. **每门至少做完一本教材 70% 的习题**。这是四大力学和普物的根本区别——普物可以靠理解，四大力学必须靠算。
2. **用 LaTeX 记录解答**，形成你自己的"作业本"。
3. **每学完一门，做一个计算项目**收尾（见[项目清单](../计算物理/项目清单.md)）。
4. **准备第二遍**。四大力学几乎不可能一遍学会，第二遍换一本更高视角的教材（如 Landau 系列）是标准做法。

## 检验标准

不要靠感觉。用[习题与解答](../习题与解答.md)里的资格考试题做检验 —— 能独立解出 Lim 系列中 50% 的题目，说明四大力学已经过关。
