# 电动力学

**地位**：四大力学中数学负担最重的一门。它把普物电磁学从"会算简单情形"提升到"能解一般边值问题"。

**典型耗时**：每周 10 小时，约 4–5 个月

## 先修要求

| 项目 | 要求 |
| --- | --- |
| 物理 | 普物电磁学（扎实） |
| 数学 | 矢量分析、**偏微分方程与分离变量法**、特殊函数（勒让德、贝塞尔）、复变（留数定理，后几章用） |

!!! danger "绝大多数卡壳发生在数学，不在物理"
    如果分离变量法和特殊函数不熟悉，Griffiths 第 3 章会完全推不动。先补[数学物理方法](../数学基础/数学物理方法.md)的相关章节。

## 核心内容

矢量分析回顾 → 静电学 → 边值问题（**核心**）→ 多极展开 → 介质中的场 → 静磁学 → 电磁感应 → 麦克斯韦方程组 → 守恒律 → 电磁波 → 势与规范 → 辐射 → 相对论与电动力学

## 教材

| 定位 | 教材 | 说明 |
| --- | --- | --- |
| **首选** | Griffiths《Introduction to Electrodynamics》 | 公认最好的入门教材，行文极友好 |
| 进阶 | Jackson《Classical Electrodynamics》 | 难度陡增，研究生资格考试标准 |
| 中文 | 郭硕鸿《电动力学》 | 国内常用 |
| 参考 | Feynman 讲义卷 II | 直觉补充 |
| 参考 | Landau《场论》（卷 2） | 与相对论统一处理，视角极高 |

!!! warning "不要一上来就啃 Jackson"
    这是最常见的自毁行为。Griffiths 做完 → Lim 系列的资格考试题 → 再考虑 Jackson。直接上 Jackson 的失败率极高。

## 常见坑

- 第 3 章（边值问题）做不透就往后赶 —— 这是全书枢纽，后面全靠它
- 不做 Griffiths 的多极展开习题，导致后面辐射部分跟不上
- 规范自由度没搞清，学到量子力学和 QFT 时会再卡一次
