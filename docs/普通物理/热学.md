# 热学

**地位**：普物中相对独立的一支，是[热力学与统计物理](../四大力学/热统.md)的铺垫。

**典型耗时**：每周 10 小时，约 1–1.5 个月

## 核心内容

温度与热平衡 → 理想气体 → 热力学第一定律 → 热机与循环 → 熵与热力学第二定律 → 输运现象 → 相变初步

!!! note "普物热学与热统的区别"
    普物热学处理的是**宏观唯象**关系（$PV=nRT$ 这类）；热统要从微观出发**推导出**这些关系。如果你打算走理论路线，普物热学可以适度精简，把精力留给热统。

## 重点提醒

- **熵是难点**。普物阶段很难真正讲清熵，通常是到热统才明白。这里先接受 $dS = \delta Q/T$ 这个操作定义即可。
- **热机循环要会算效率**。卡诺循环必须能独立推导。

## 常见坑

- 混淆"热量""内能""温度"三个概念
- 弄不清准静态过程与可逆过程的区别
