# 力学

**地位**：起点。它是第一个把微积分真正用起来的地方，也是建立"建模—列方程—求解—检验"这套物理工作流的地方。

**典型耗时**：每周 10 小时，约 1.5–2 个月

## 先修要求

| 项目 | 要求 |
| --- | --- |
| 数学 | 一元微积分（必须）、矢量 |
| 计算 | 会用 `scipy.integrate.solve_ivp` |

## 核心内容

运动学 → 牛顿定律 → 功与能 → 动量与碰撞 → 转动与角动量 → 刚体 → 振动 → 万有引力与轨道 → 流体力学初步

!!! note "重点：能量与动量守恒"
    这两条守恒律是整个物理学的骨架。学到后面会发现，拉格朗日力学和诺特定理就是在讲"为什么会有守恒律"。

## 常见坑

- **以为高中物理好就能跳过**。大学力学的差别在于微积分的深度使用和刚体转动，不是重复高中内容。
- **只做平动不做转动**。转动惯量、角动量守恒是后面理论力学的基础，必须做透。
- **不做守恒律检验**。养成习惯：算完一道题，检查能量和动量是否守恒。
