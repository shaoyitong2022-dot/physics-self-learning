# 普通物理

**地位**：整个体系的地基。即使是物理专业出身，如果当年学得糊，也建议快速过一遍 —— 四大力学是建立在普物的直觉之上的。

**典型耗时**：每周 10 小时，约 5–7 个月（全部五科）

## 顺序

1. [力学](力学.md)　→　2. [电磁学](电磁学.md)　→　3. [热学](热学.md)　→　4. [光学](光学.md)　→　5. [近代物理](近代物理.md)

力学必须第一（它是矢量分析和微分方程的第一个练兵场），电磁学第二（最难，需要矢量积分），热学/光学可以并行，近代物理最后（它是通往量子力学的桥）。

## 通用建议

!!! tip "普物的关键是做题，不是看懂"
    普物概念看起来简单，实际非常容易"以为懂了"。检验标准只有一条：**做 Irodov 或《难题集萃》的题能独立解出来吗**。建议每科做完 100–200 道题。

## 教材选择

见[教材推荐](../教材推荐.md)。推荐组合：

- 主线：**Young & Freedman《University Physics》** 或 **赵凯华《新概念物理教程》**
- 直觉补充：**Feynman《物理学讲义》**（在线免费，学完一章后读对应章节）
- 习题：**Irodov** 或 **《物理学难题集萃》**

## 弯道提示

- 已有理工科基础的人可以**跳过力学的 smooth 部分**，直接做难题检验
- 电磁学是普物里最难的，不要因为卡在这里就怀疑自己
- 光学在现代物理里地位下降，可以适度精简，但干涉衍射部分要会
