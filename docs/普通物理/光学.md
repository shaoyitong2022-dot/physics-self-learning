# 光学

**地位**：在现代物理体系里地位有所下降，但干涉、衍射、偏振是必备基础，且是[AMO](../轨道/AMO.md)、量子光学的前置。

**典型耗时**：每周 10 小时，约 1 个月

## 核心内容

几何光学 → 干涉 → 衍射 → 偏振 → 光与物质相互作用初步

## 建议的取舍

| 内容 | 建议 |
| --- | --- |
| 几何光学（透镜公式等） | **可以快速过**，会算即可 |
| 干涉（双缝、薄膜、迈克耳孙干涉仪） | **必须做透**，这是重点 |
| 衍射（单缝、光栅、夫琅禾费/菲涅耳） | **必须做透**，是难点 |
| 偏振 | 理解即可 |
| 傅里叶光学 | 选学，做计算方向很有用 |

## 视频课程

- MIT 8.03（Vibrations and Waves）—— 波动基础讲得极好，学光学前建议先看
- 各校光学公开课

!!! tip "先学波动再学光学"
    光学本质就是波动。如果 8.03 这类"振动与波"的课程没上过，建议先看一遍，光学会顺畅很多。

## 配套计算项目

- 夫琅禾费衍射图样的 FFT 计算
- 光栅衍射的数值模拟
- 薄膜干涉的反射率计算

## 常见坑

- 死记干涉条件而不理解**光程差**的概念
- 分不清近场（菲涅耳）与远场（夫琅禾费）衍射
