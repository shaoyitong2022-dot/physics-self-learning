# 电磁学

!!! danger "这是普通物理里最难的一门"
    卡在这里是**正常的**，不代表你不行。它难在两个地方同时压过来：物理概念抽象（场），数学工具吃重（矢量积分）。

**典型耗时**：每周 10 小时，约 2–3 个月

## 先修要求

| 项目 | 要求 |
| --- | --- |
| 数学 | 多元微积分、线积分/面积分、**矢量分析（梯度/散度/旋度）** |
| 物理 | 力学（含转动） |

!!! note "卡住的真正原因通常是数学"
    如果你在做高斯定理/安培环路相关的题时频繁出错，先回去补[矢量分析](../数学基础/微积分.md)，而不是死磕物理。

## 核心内容

静电场 → 高斯定理 → 电势 → 导体与电容 → 电流与电路 → 磁场 → 安培定律 → 法拉第电磁感应 → 电感 → 麦克斯韦方程组 → 电磁波

## 教材

| 定位 | 教材 |
| --- | --- |
| **标准** | Young & Freedman《University Physics》电磁学部分 |
| 提前看 | **Griffiths《Introduction to Electrodynamics》第 1–7 章** —— 普物阶段就可以直接上 Griffiths 的前半本，讲得比普物教材清楚得多 |
| 中文 | 赵凯华《新概念电磁学》；胡友秋《电磁学》 |
| 习题 | Irodov 电磁学部分（难）；Griffiths 习题（推荐） |
| 参考 | Feynman 讲义卷 II —— 电磁学直觉的最佳补充 |

!!! tip "推荐一个激进但高效的做法"
    如果你数学底子不错，**直接用 Griffiths 前七章代替普物电磁学教材**。Griffiths 的行文友好度远高于一般普物教材，只是习题要求稍高。这也是为后续[电动力学](../四大力学/电动力学.md)铺路。

## 常见坑

- **混淆电场与电势**。记住：$\mathbf{E} = -\nabla V$，电场是电势的负梯度。
- **不会选高斯面**。高斯定理只在对称性足够时才好用，判断对称性是第一步。
- **跳过法拉第定律**。电磁感应是唯一连接电与磁的环节，也是最难直觉化的部分，要多花时间。
- 不做 [Irodov](../习题与解答.md) 的电磁学部分就以为自己会了 —— 这一块题目能显著暴露问题。
