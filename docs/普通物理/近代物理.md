# 近代物理

**地位**：通往[量子力学](../四大力学/量子力学.md)的桥。这一门学得好不好，直接决定量子力学的起步难度。

**典型耗时**：每周 10 小时，约 1.5 个月

## 核心内容

狭义相对论 → 黑体辐射与普朗克假设 → 光电效应与光子 → 康普顿散射 → 玻尔模型 → 物质波与德布罗意关系 → 薛定谔方程初步 → 原子结构 → 核物理初步 → 粒子物理初步

!!! note "最重要的是建立'量子化'这个观念"
    这门课的作用不是让你会算，而是让你接受"能量是离散的""粒子也是波"这些反直觉的事实。**先接受规则，直觉会自己长出来。**

## 重点提醒

- **狭义相对论要会洛伦兹变换**，不要只停留在"时间膨胀"这种科普层面
- **氢原子的玻尔模型要能推导**，尽管它后来会被量子力学取代
- **不要在这里纠缠量子力学的诠释问题**，那是后面才该想的事

## 常见坑

- 用经典直觉硬套量子现象，越想越乱
- 跳过狭义相对论直接上量子（两者是独立的，但都重要）
- 把科普书当教材读 —— 科普不能替代计算训练
