# 科研训练：如何自己培养科研能力

!!! note "这一页回答一个问题"
    不上课、不进组，能不能自己练出科研能力？**能，但必须按正确的方式练。**

    大部分人以为"科研能力 = 读了很多论文"。这是错的。读完 50 篇论文你可能仍然做不了科研。

## 一、科研能力到底是什么

拆开来看，科研能力是四件事的组合：

| 能力 | 具体是什么 | 课堂能给你吗 |
| --- | --- | --- |
| **复现能力** | 看懂别人的推导/代码，能自己重做一遍并得到相同结果 | 部分能（做题） |
| **提问能力** | 在已知结果旁边找到一个值得问的小问题 | **不能**，这是科研的核心 |
| **执行能力** | 把模糊的问题拆成可执行的步骤，一步步推下去 | **不能** |
| **表达能力** | 把结果写成别人能看懂、能验证的形式 | **不能** |

!!! danger "关键差别"
    课程训练的终点是"做出已知答案的题"；科研训练的起点是"**提出一个没人知道答案的问题，并把它做出来**"。

    这个跨越，大部分人在博士头两年才完成——而且往往是痛苦地完成的。**但它可以提前练。**

## 二、四步训练法

这是自学科研能力的可执行路径，按顺序走，不要跳步。

### 第 1 步：复现（Reproduce）

**做什么**：找一篇**有公开代码或足够细节**的小论文，把它的主要结果自己重算一遍。

**怎么找**：

- arXiv 上找近 5 年、引用量 10–50 之间、作者给了代码的论文（太经典的往往细节省略太多，太新的可能还没被验证）
- 教材里的"进阶应用"章节
- 各校公开的研究生课程项目（如 MIT、Caltech 的课程 project）

**标准**：你算出来的图，应该和论文里的图**长得一样**。

**这一步会教给你**：论文里省略的"显然"步骤到底有多不显然。这是最震撼的一课——你会发现论文里一句"由简单计算可得"，你算了三个晚上。

!!! tip "建议的第一个复现项目"
    从[计算物理项目清单](计算物理/项目清单.md)里挑，它们都是可复现的经典结果。做完 5 个之后，再去 arXiv 上找真正的论文。

### 第 2 步：提问（Ask）

复现完之后，问自己几个问题：

- 这个结果在**参数变化**时会怎样？（试试改参数）
- 作者做了什么**近似**？如果去掉这个近似会怎样？
- 这个方法能不能用到**另一个系统**上？
- 论文里"我们留待将来研究"的那句话，具体指的是什么？

!!! note "从哪找到好问题"
    好问题通常藏在三个地方：
    1. **论文的 limitations / outlook 段**——作者自己告诉你哪里没做完
    2. **两个方法结论不一致的地方**
    3. **把 A 领域的方法用到 B 领域**（这是最容易出原创成果的路径）

### 第 3 步：独立做（Execute）

选定一个小问题，自己推下去。这一步的关键是**控制规模**：

| 规模 | 说明 |
| --- | --- |
| 太小 | 只是练习，没有新东西 |
| **合适** | 2–8 周能做完，有一个明确的小结果（哪怕只是"在某某情形下，X 会怎样"） |
| 太大 | 会卡死，这是自学科研最常见的死法 |

**执行纪律**：

- 每天记 log（今天做了什么、卡在哪、明天打算做什么）
- 卡住超过 3 天，就换角度——不要死磕
- 中途一定要做"最小可用结果"：先跑通一个简化版本，再逐步加复杂

### 第 4 步：写出来（Write）

!!! warning "不做这一步，前面的都不算数"
    科研的成果**只以可复现、可验证的形式存在**。你脑子里懂了不算。

**最低标准**：一份用 LaTeX 写的报告，包含：

1. 问题是什么
2. 你用的方法（详细到别人能重现）
3. 结果（图 + 表）
4. 与已知结果的对比/检验
5. 结论与局限
6. **代码**（推到 GitHub，能跑通）

**进阶**：写成 preprint 挂 arXiv（本科生可以，但需要 endorsement 或由教授提交——这是进组的好处之一）。

## 三、怎么读论文

!!! tip "不要从头读到尾"
    顺序：**标题 → 摘要 → 图表 → 结论 → 决定要不要读正文**。

    一篇论文平均值得你花的时间差异极大。第一次读一篇陌生论文超过 2 小时还没懂，通常是**前置知识不够**，应该退回去补教材，而不是硬读。

**进入一个新领域的阅读顺序**：

1. **综述 / Review**（搜 "(topic) review arXiv"，或看 *Reviews of Modern Physics*、*Physics Reports*）
2. **经典原始论文**（教材里通常会引用）
3. **近三年的博士论文**（学位论文的引言比论文好读得多，是绝佳入门材料）
4. **顺着引用链往回走**（INSPIRE-HEP / Google Scholar）
5. **最后读最新进展**

**阅读工具**：Zotero 管理文献，配合 BibTeX。每篇记一句话总结 + 用到的关键方法。详见[文献检索](工具箱/文献检索.md)。

## 四、工程纪律（这部分常被物理学生忽略）

科研不是只有物理，它还有工程。以下习惯会让你和"野路子自学者"拉开差距：

| 习惯 | 为什么 |
| --- | --- |
| **用 Git** | 版本管理。你会无数次需要回退到三天前的版本 |
| **代码能从头跑通** | Notebook 要能 `Restart & Run All` 通过 |
| **固定随机种子** | 结果必须可复现 |
| **做收敛性检验** | 网格加密、步长减半，误差应按理论阶数下降 |
| **写 README** | 三个月后的你会忘记现在的代码在干什么 |
| **量纲与极限检验** | 物理工作者区别于程序员的地方 |

## 五、怎么找到导师 / 进组

!!! danger "自学有上限"
    自学科研能让你达到"能干活"的水平，但**到不了"能做真正重要的工作"**。科研的品味、选题判断、隐性知识，都只能从人身上学。

    **所以：练到一定程度，一定要进组。**

**怎么找**：

1. **本校课题组**：最直接。先去课题组主页看他们在做什么，读他们最近的一两篇论文，然后带着具体问题去办公室找老师
2. **暑期科研**：国内各校的暑期学校/科研实习；海外的 REU（美国）、DAAD（德国）等
3. **主动联系**：邮件要具体——说明你读过他的哪篇论文、你的问题是什么、你能做什么（附上你的 GitHub 或项目报告）

**套磁邮件的要点**：

- 短（半屏以内）
- 具体（提到对方的某篇具体工作）
- 展示能力（附上你复现/做过的东西）
- 不要群发模板（教授一眼看得出来）

## 六、可交付物清单

用来衡量你的科研训练进度：

- [ ] 复现过 3 篇以上论文的主要结果
- [ ] 有一个自己的 GitHub 仓库，包含 10 个以上计算项目
- [ ] 每个项目有 README、能跑通、有检验
- [ ] 用 LaTeX 写过至少一份完整的技术报告
- [ ] 独立提出并解决过一个小问题
- [ ] 熟悉至少一个领域的文献（能说出该领域的三个 open problems）
- [ ] 参加过一次组会/学术报告并提问

!!! note "这些就是你的简历"
    申请研究生、找实习、找工作，你能拿出来的东西就是这些。**它们比成绩单更有说服力。**

## 常见坑

- **一直复现，不肯开始自己提问** —— 复现是手段不是目的，做完 3–5 个就该往前走
- **选题太大** —— 自学科研的头号死法。控制在 2–8 周
- **不写下来** —— 三个月后你会忘记自己做过什么，等于白做
- **不看代码只看公式** —— 现代科研里代码和公式同等重要
- **闭门造车太久** —— 练半年到一年后必须找人讨论，否则会陷入自嗨
