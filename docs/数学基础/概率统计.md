# 概率与统计

**服务于**：热力学与统计物理（核心）、量子力学的概率诠释、实验数据处理、机器学习物理。

## 核心内容

| 主题 | 服务于 |
| --- | --- |
| 概率空间、条件概率、贝叶斯定理 | 统计推断 |
| 随机变量、分布、期望 | 全部 |
| 大数定律与中心极限定理 | 统计物理的基础直觉 |
| 组合数学（斯特林公式） | 熵的推导（必会） |
| 多元分布、协方差、相关性 | 误差分析、MCMC |
| 随机过程、马尔可夫链 | 蒙特卡洛方法、非平衡统计 |
| 信息论、熵 | 统计物理、量子信息 |

!!! note "斯特林公式 $\ln N! \approx N\ln N - N$"
    这一个近似撑起了整个统计物理。理解它为什么成立、什么时候失效，比记住很多公式都重要。
