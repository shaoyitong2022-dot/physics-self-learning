# 数学物理方法

这是"物理系的数学课"——把微积分、线代、复变、PDE 按物理的需求打包在一起。

**何时学**：建议在四大力学之前或与之并行，是电动力学和量子力学的直接前置。

## 核心内容

| 主题 | 服务于 |
| --- | --- |
| 复变函数、解析性、柯西定理 | 留数定理的基础 |
| **留数定理** | 复杂实积分、QFT 的围道积分（必会） |
| 特殊函数（勒让德、贝塞尔、厄米、拉盖尔） | 球谐函数、氢原子、柱对称问题 |
| 傅里叶级数与变换 | 贯穿全程 |
| 拉普拉斯变换 | 电路、线性响应 |
| 变分法 | 理论力学（拉格朗日方程的来源） |
| 格林函数 | 边值问题、散射理论 |
| 张量分析 | 电动力学、广义相对论 |

## 资源

| 定位 | 资源 |
| --- | --- |
| **首选** | Boas《Mathematical Methods in the Physical Sciences》—— 用中学，卡哪查哪 |
| 系统 | Arfken & Weber《Mathematical Methods for Physicists》 |
| 中文 | 梁昆淼《数学物理方法》—— 国内标准教材 |
| 复变 | Brown & Churchill《Complex Variables and Applications》 |
| 课程 | MIT 18.075 / 各校"数学物理方法"公开课 |

!!! tip "不要通读 Arfken"
    它是参考书，不是教材。通读 Arfken 是另一种形式的拖延症。正确用法：Boas 为主，Arfken 查缺。
