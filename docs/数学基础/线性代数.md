# 线性代数

!!! danger "这是物理最重要的数学课"
    量子力学的语言就是线性代数。本征值、内积空间、厄米算符、完备正交基——这些不是"数学工具"，它们就是量子力学本身。**90% 的"量子力学太难"其实是线代没过关。**

## 核心内容

| 主题 | 服务于 |
| --- | --- |
| 矩阵运算、行列式 | 全部 |
| 本征值与本征向量 | 量子力学、简正模式、转动惯量 |
| 内积空间、正交归一 | 量子力学（核心） |
| 厄米 / 酉矩阵 | 量子力学（可观测量、演化算符） |
| 对角化与谱定理 | 量子力学、振动问题 |
| 张量积 | 量子纠缠、多粒子系统 |
| 广义本征值问题 | 多自由度小振动 |
