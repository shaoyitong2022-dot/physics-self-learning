# 微分方程

**服务于**：几乎全部物理。物理定律大多以微分方程的形式表述。

## 常微分方程（ODE）

| 主题 | 服务于 |
| --- | --- |
| 一阶 ODE、分离变量 | 力学、电路 |
| 二阶线性 ODE、常系数 | 阻尼振动、RLC 电路 |
| 级数解法 | 特殊函数（勒让德、贝塞尔）的引入 |
| 相图与稳定性分析 | 非线性动力学、混沌 |
| 摄动法 | 非微扰问题的近似 |

## 偏微分方程（PDE）

| 主题 | 服务于 |
| --- | --- |
| 分离变量法 | 电动力学边值问题（核心技能） |
| 本征函数展开 | 热传导、波动方程 |
| 格林函数 | 电动力学、量子散射 |
| 波动方程 / 扩散方程 / 拉普拉斯方程 | 三大基本方程 |
| 傅里叶变换 | 贯穿全程 |

!!! note "分离变量法是硬门槛"
    电动力学的边值问题（Griffiths 第 3 章）几乎全部依赖它。这一块不过关，电动力学一定崩。
