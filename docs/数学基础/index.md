# 数学预备

!!! warning "不要试图先把数学学完"
    这是自学物理的头号陷阱。数学应该**永远领先物理半步**，而不是领先一步。看到不懂的数学就回头从头重修数学教材，会让你在实分析里耗死。

**正确做法**：查[学习规划](../学习规划.md)里的数学↔物理对应表，只补当下用到的那一块，然后立刻回到物理。

## 推荐策略

| 情况 | 做法 |
| --- | --- |
| 卡在某个具体技巧（如留数定理） | 查 Boas《Mathematical Methods in the Physical Sciences》对应章节，学完即用 |
| 某块基础整体薄弱（如线代） | 单独补一次，用 3Blue1Brown 建直觉 + MIT 18.06 练运算 |
| 想系统补齐 | 按本模块顺序走，但**与物理课并行**，不要串行 |
