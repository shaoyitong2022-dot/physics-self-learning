# 微积分与矢量分析

**服务于**：力学、电磁学、几乎全部物理

## 核心内容

| 主题 | 什么时候需要 |
| --- | --- |
| 一元微积分 | 力学起步（必须已经会） |
| 多元微积分、重积分 | 电磁学、连续介质 |
| 线积分、面积分、体积分 | 电磁学（高斯定理、斯托克斯定理） |
| 梯度 / 散度 / 旋度 | 电磁学、流体 |
| 曲线坐标（球坐标、柱坐标） | 电动力学的边值问题 |
| 泰勒展开与渐近分析 | 贯穿全程，物理学家最常用的工具 |

!!! note "矢量分析是分水岭"
    很多人在电磁学卡住，不是因为不懂物理，而是**不会算矢量积分**。高斯定理和斯托克斯定理要能熟练使用，而不是只会背公式。
