# 前言

> *物理不是一门"听课"的学科，是一门"算题"的学科。*

## 为什么物理系学生需要一本自学手册

这不是写给零基础爱好者的入门指南。**这是写给在读物理系学生的。**

我们都经历过这样的困境：一门很重要的课，老师照着一本二十年前的教材念 PPT，你听得云里雾里；课后去找答疑，发现助教自己也说不清楚；作业发下来只有分数没有过程；去网上搜，搜到的是一堆质量参差的笔记和答非所问的帖子。

而与此同时，世界上最好的物理课和最好的教材，几乎都已经在网上免费公开了——

- Griffiths 把电动力学和量子力学写得像小说一样好读；
- Feynman 的三卷讲义全文免费在线；
- MIT、Berkeley、Perimeter 的课程录像随便看；
- David Tong 的场论讲义比大多数出版教材讲得清楚。

问题从来不是"没有好资源"，而是**资源太多、良莠不齐，且没人告诉你该按什么顺序读**。

这正是这本书想做的事：把分散在整个互联网上的优质物理资源，按照一个物理系学生的真实学习路径组织起来，并在每一个节点告诉你 —— 读哪本、看谁的课、做哪些题、什么时候该换教材、哪里最容易栽跟头。

## 课堂与自学的关系

!!! warning "先说清楚一件事"
    本书**不鼓励翘课自学**。原因很实际：

    - GPA 对保研、出国、奖学金都是实打实的硬指标；
    - 课内有 DDL、有考试、有同伴，这些外部约束是稀缺的推进力，自学恰恰最缺这个；
    - 实验课、讨论班、与老师的当面交流，是自学永远补不上的部分。

    自学的正确用法是**补课堂，不是替课堂**：课堂用来过进度、拿学分，自学用来把没讲透的东西真正学明白。两者并行，而不是二选一。

具体来说：

| 场景 | 做法 |
| --- | --- |
| 老师讲得好 | 跟着课堂走，用本书的习题资源加练 |
| 老师讲得一般 | 课堂保持出勤与分数，用本书的教材/课程**重学一遍** |
| 想提前学 | 按本书的轨道规划超前推进 |
| 想拔高 / 准备科研 | 走本书的进阶轨道 |

## 自学的三个真实好处

**一、可以反复。**课堂上老师讲一遍就过去了，录像和教材可以让你在任何一个卡住的地方停下来，反复看、反复想，直到弄明白。

**二、可以博采众长。**四大力学每一门我都建议读两本教材——不同的讲法、不同的侧重点、不同的习题，能纠正你从单一教材里形成的错误理解。这是课堂给不了的。

**三、进度自由。**掌握得快的地方可以加速，卡住的地方可以扎下去，不必被统一的教学进度拖着走。

## 自学的三个真实困难

**一、没人判卷。**这是物理自学最致命的问题。CS 有 autograder，物理没有。解决办法只有一个：用公开的习题解答库核对（见[习题与解答](习题与解答.md)）。

**二、没有实验室。**普物和中级物理实验在家做不了。这是结构性缺口，本书用[计算物理项目](计算物理/项目清单.md)尽量弥补，但不能假装它不存在。

**三、自律。**没有 DDL 有时很可怕。你得自己逼着自己读完几十页教材、做完几十道题。没有学分，没有绩点，只有一个信念——你在变强。

!!! tip "对抗拖延最有效的办法"
    给自己制造可见的产出：用 LaTeX 记录每一道做过的题，用 GitHub 保存每一个计算项目。当你的仓库里有 200 页解答和 10 个项目时，你不会想停下来。

## 这本书适合谁

- **在读物理系本科生**，觉得某门课没学明白，想换一条路重学
- 想**提前推进**、为保研或出国打基础的人
- 想**进入某个研究方向**却不知道从哪下手的高年级学生
- 准备考研，需要一份系统的复习与拔高清单的人
- 也欢迎物理专业出身、想补回基础的跨学科研究者
