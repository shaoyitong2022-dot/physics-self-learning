# 前言

> 物理不是一门"听课"的学科，是一门"算题"的学科。

## 为什么要写这本手册

CS 领域有一份 [CS 自学指南](https://csdiy.wiki)，它之所以成立，是因为 CS 的教育资源具备三个罕见的条件：**课程网站一站集成、教材配套、作业自动评分**。你跟着 MIT 6.S081 做 lab，做错了会有脚本告诉你错在哪。

物理自学的处境完全不同：

- 名校公开课很多，但**作业和答案常常缺失或不公开**，你做完一道 Jackson 的题，没人告诉你对不对；
- 物理的"大作业"是**习题**，而经典教材（Jackson、Sakurai、Landau）的习题难度跨度极大，自学时极易卡死或走神；
- 物理严重依赖**数学工具**的同步推进，学到电动力学才发现自己不会解偏微分方程，是常态；
- 物理的**实验环节**几乎无法在家完成——这是自学物理最大的结构性缺口。

但物理自学也有 CS 没有的优势：

- 经典教材的质量高得离谱。Griffiths、Feynman、Landau、Feynman 讲义在线免费，这些书本身就是"好老师"；
- **中文资源是一流的**。中科大、北大、清华的物理课程录像与讲义质量不输欧美，大量经典教材有优秀中译本；
- 有一批**公开的习题解答宝库**（Lim Yung-Kuo 的资格考试题系列、各校 Qualifying Exam 题库、民间解答集），把"没人判卷"这个短板补上了大半；
- 最关键的是：**计算物理可以替代实验**。写一段代码数值求解薛定谔方程、跑一个 Ising 模型的蒙特卡洛、做一个 N 体星系模拟——这些项目既是练习，也是可展示的成果，是现代物理自学者唯一的"实验室"。

这本手册想做的，就是围绕这些真实差异，给出一条可执行的路线。

## 这本书的目标读者

- 想系统补齐物理基础的非物理专业学生 / 转行者
- 本专业觉得课堂讲得不好，想换一条路重学的物理本科生
- 已经工作，想把物理学明白的爱好者
- 准备考研 / 出国，需要一份复习与拔高清单的人

## 本书不做什么

- **不替代教材**。本书是索引与路线，正文靠你读教材。
- **不承诺速成**。四大力学扎实走完，以每周 10 小时计，大约需要 1.5–2 年。
- **不回避数学**。凡是会卡住你的数学工具，都会明确标注"需要同步修哪门数学"。
