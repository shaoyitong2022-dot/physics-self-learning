## 怎么选方向

自学选方向不能靠"感不感兴趣"——你没接触过，谈不上感兴趣。建议按下面三个可操作的判据：

| 判据 | 说明 |
| --- | --- |
| **你擅长哪种数学** | 喜欢代数与对称性 → 高能；喜欢分析与偏微分方程 → 流体/GR；喜欢概率与统计 → 软物质/生物物理 |
| **你要多快看到反馈** | 想几个月出成果 → 计算方向、AMO；能接受长期投入 → 高能理论 |
| **你有没有实验条件** | 纯自学者做实验方向很难，优先考虑理论与计算方向 |

!!! tip "一个务实的建议"
    先花两周时间，每个方向挑一篇最近的综述读摘要和图表，看哪个让你"想知道更多"。这比空想有效得多。

## 通用提醒

- 方向课**没有公认标准路径**，教材选择差异很大，多备几本对照
- 到了这一层，**读论文的重要性开始超过读教材**
- 尽量找一位导师或加入课题组 —— 自学到这一步，瓶颈从"资源不足"变成了"没人讨论"
