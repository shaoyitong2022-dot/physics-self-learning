# 如何使用这本书

## 先做一件事：定位自己

| 你现在的状态 | 从哪开始 | 优先路线 |
| --- | --- | --- |
| 高中/大一，数学只有初等微积分 | [数学基础](数学基础/index.md) + 普通物理 · 力学 | 路线 A |
| 理工科在读，高数线代已修 | 普通物理快速过一遍 → 直奔四大力学 | 路线 A |
| 已工作 / 转行，想见效快 | [计算物理](计算物理/index.md) 优先，按需补理论 | 路线 B |
| 纯兴趣，不打算做题 | Feynman 讲义 + Susskind 系列 | 路线 C |
| 考研 / 出国复习 | [习题与解答](习题与解答.md) + 对应科目页面 | 按目标科目 |

## 三个使用原则

### 1. 数学永远领先半步，不要领先一步

看到"数学不够"就想回头从头重修，是自学物理的头号时间黑洞。正确做法：查[数学贯穿线对应表](学习规划.md)，只补当前用到的那一块，立刻回到物理。

### 2. 做题量 > 阅读量

物理和 CS 最大的区别：CS 看懂代码就能跑，物理看懂推导**不等于会做**。判断标准是：合上书，能否独立推出结果。

建议比例：读 1 小时 ↔ 做题 1.5 小时。

### 3. 每学完一个板块，用代码实现一次

这是本书与多数物理资源清单不同的地方。**计算项目是自学者的实验室**——没有它，你永远不知道自己算得对不对。

## 建议的节奏

以每周 10 小时为基准（这是可持续的下限，低于 5 小时/周效果会显著下降）：

- 3 小时　读教材 / 看课程录像
- 5 小时　做题（用 LaTeX 记录解答）
- 2 小时　计算项目或仿真

## 怎么判断"学到位了"

不要靠感觉，用可验证的标准：

| 阶段 | 检验标准 |
| --- | --- |
| 普通物理 | 能独立解出 Irodov 中 60% 的题 |
| 理论力学 | 能写出一个非平凡系统的拉格朗日量并导出运动方程 |
| 电动力学 | 能独立做完 Griffiths 第 3 章（边值问题）的大部分习题 |
| 量子力学 | 能独立推导出谐振子的升降算符解和氢原子的能级 |
| 热统 | 能独立算出几个非平凡模型的配分函数并导出状态方程 |
| 计算物理 | 独立完成[项目清单](计算物理/项目清单.md)中至少 8 个项目 |
