# 如何使用这本书

本书的核心组织方式是**轨道**。先按你的目标选一条轨道，再按你每周能投入的时间调整节奏。

## 第一步：选轨道

| 轨道 | 适合谁 | 起点 | 出口 |
| --- | --- | --- | --- |
| **[0　同步补强](轨道/同步补强.md)** | 低年级，某门课没学明白，想换资源重学 | 你现在卡住的那门课 | 把课内补到扎实 |
| **[A　理论物理](轨道/理论物理.md)** | 想做理论、想读博、想出国 | 学完四大力学 | 能读论文、进组 |
| **[B　凝聚态与材料](轨道/凝聚态.md)** | 对固体、超导、拓扑、量子材料感兴趣 | 四大力学 | 进入凝聚态课题组 |
| **[C　高能·天体·宇宙学](轨道/高能天体.md)** | 想做粒子物理、天体、宇宙学 | 四大力学 + QFT/GR | 进入相关课题组 |
| **[D　AMO 与量子信息](轨道/AMO.md)** | 对冷原子、量子计算、精密测量感兴趣 | 量子力学扎实 | 进入 AMO/量子信息组 |
| **[E　计算与交叉](轨道/计算AI量化.md)** | 想转量化/AI/数据，或做计算物理 | 数值方法 + 统计物理 | 可展示的作品集 |
| **[F　考研与保研](轨道/考研.md)** | 大三，目标明确：考上去 | 普物 + 量子力学 | 应试能力最大化 |
| **[G　流体与非线性](轨道/流体非线性.md)** | 对非线性、湍流、复杂系统感兴趣 | 理论力学 + PDE | 进入相关课题组 |

!!! tip "不确定选哪条？"
    选 **轨道 0**（同步补强）。在你把四大力学真正学扎实之前，方向选择往往只是想象——你还没见过那些方向真正长什么样。

    想快速感知各个方向：去 arXiv 上每个分类（`cond-mat`、`hep-th`、`astro-ph`、`quant-ph`）各挑一篇最近的综述，只读摘要和图表，看哪个让你想知道更多。这比空想有效得多。

## 第二步：按时间预算调整

同一条轨道，投入不同，走法完全不同。这是最容易被忽视的一点。

| 每周可投入 | 现实情况 | 建议做法 |
| --- | --- | --- |
| **5 小时以下** | 课业极重 / 有科研任务 | 不要开新战线。只做一件事：**把当前最弱的一门课的习题补上去**。贪多必崩 |
| **5–10 小时** | 正常学期中的可持续投入 | 一条主线推进（如一门四大课）+ 一个计算项目。约 4–6 个月一门课 |
| **10–20 小时** | 假期 / 课业轻松的学期 | 两条线并行（如量子力学 + 统计物理），或一条线 + 密集做题 |
| **20 小时以上** | 暑假 /  gap 期 | 可以集中突破一门硬课（如 Jackson、Peskin），**但不要超过 8 周**——长期高强度不可持续 |

!!! warning "别按假期强度做学期计划"
    最常见的规划错误：暑假里一天学六小时，于是给自己定了学期内每周 20 小时的计划，开学第三周就崩了。**按你能持续的最低值规划，而不是按峰值。**

## 第三步：把课内和自学接起来

| 你在课内正在学 | 自学这边同步做 |
| --- | --- |
| 力学 / 电磁学 | 换 Griffiths 或 Morin 的习题加练 |
| 理论力学 | 补 Goldstein，用 Landau 提视角 |
| 电动力学 | Griffiths 从头做透，第 3 章边值问题重点 |
| 量子力学 | Griffiths 主攻 + Sakurai 第二遍 |
| 统计物理 | Schroeder 打底 + Kardar 拔高 |
| 数学物理方法 | Boas 用中学，卡哪查哪 |

## 三个贯穿全程的原则

### 1. 数学永远领先半步，不要领先一步

看到"数学不够"就想回头从头重修数学，是自学物理的头号时间黑洞。查[数学贯穿线对应表](学习规划.md)，只补当前用到的那一块，立刻回到物理。

### 2. 做题量 > 阅读量

判断标准是：合上书，能否独立推出结果。建议比例——读 1 小时 ↔ 做题 1.5 小时。

### 3. 每学完一个板块，用代码实现一次

这是本书与多数资源清单不同的地方。**计算项目是自学者的实验室**——没有它，你永远不知道自己算得对不对。

## 怎么判断"学到位了"

不要靠感觉，用可验证的标准：

| 阶段 | 检验标准 |
| --- | --- |
| 普通物理 | 能独立解出 Irodov 中 60% 的题 |
| 理论力学 | 能写出一个非平凡系统的拉格朗日量并导出运动方程 |
| 电动力学 | 能独立做完 Griffiths 第 3 章（边值问题）的大部分习题 |
| 量子力学 | 能独立推导出谐振子的升降算符解和氢原子的能级 |
| 热统 | 能独立算出几个非平凡模型的配分函数并导出状态方程 |
| 计算物理 | 独立完成[项目清单](计算物理/项目清单.md)中至少 8 个项目 |
| 进入科研 | 能复现一篇小论文的主要结果 |
