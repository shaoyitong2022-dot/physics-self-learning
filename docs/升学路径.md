# 升学路径：保研 / 直博 / 出国

!!! warning "本页讲策略与权重，具体政策请核实"
    各校保研政策、申请要求每年都在变。**具体的分数线、名额、截止日期请以当年官方通知为准。**本页讲的是不变的东西：各项因素的权重排序与时间线。

## 一、三条路的对比

| | 保研（推免） | 考研 | 出国 PhD |
| --- | --- | --- | --- |
| 决定因素 | GPA 排名 + 科研 + 竞赛 | 统考分数 | 科研 + 推荐信 + GPA |
| 准备周期 | 整个大学前三年 | 大三下–大四上集中备考 | 大一到申请季 |
| 风险 | 拿不到名额则无 | 一考定生死 | 申请不确定性大 |
| 时间成本 | 最低（无缝衔接） | 高（半年到一年） | 最高（5–6 年博士） |
| 适合谁 | 成绩稳定在前 20–30% | 成绩靠后但应试强 | 想做顶尖科研、愿意长期投入 |

!!! tip "能保研就保研"
    保研是性价比最高的路：不需要额外备考时间，风险低，且国内顶尖组（清华、北大、中科大、物理所等）的水平完全不输海外。**如果成绩在保研线附近，优先把 GPA 拉上去。**

## 二、各项因素的权重（这是最关键的信息）

### 保研 / 直博（国内）

| 因素 | 权重 | 说明 |
| --- | --- | --- |
| **GPA / 专业排名** | ★★★★★ | 决定你能不能拿到推免名额，是门票 |
| **科研经历** | ★★★★ | 决定你能去多好的组。有论文/项目经历的人夏令营优势巨大 |
| **英语** | ★★★ | 六级是门槛，部分项目要求更高 |
| **竞赛 / 其他** | ★★ | 数模、物理竞赛等是加分项 |
| **面试表现** | ★★★★ | 夏令营/推免面试，会问专业课细节和你的科研经历 |

### 出国 PhD（美国为主）

| 因素 | 权重 | 说明 |
| --- | --- | --- |
| **科研经历** | ★★★★★ | **最决定性**。有没有做出过东西、导师怎么说你 |
| **推荐信** | ★★★★★ | 三封强推 >> 一切。来自有国际声誉的导师尤其有用 |
| **GPA** | ★★★★ | 过线即可，之后边际收益递减（3.7 和 3.9 差别不大） |
| **TOEFL** | ★★★ | 过线即可（各校有最低分），口语单项常被单独要求 |
| **Physics GRE (Sub)** | ★★ | 部分学校要求或推荐，**中国学生普遍分数很高**，高分不加分但低分扣分 |
| **PS / SOP** | ★★★ | 讲清楚你做过什么、想做什么 |

!!! danger "中国学生最大的误区"
    很多人花一年刷 TOEFL 和 GRE，却没有任何科研经历。**这在顶尖项目的申请中是致命的。**

    招生委员会想招的是"能做出东西的人"，不是"考试成绩好的人"。考试成绩只是门槛，过线之后，决定性因素是科研。

## 三、时间线

### 大一–大二：打地基

- [ ] **把 GPA 拉到最高**。这是保研的门票，也是出国的门槛
- [ ] 四大力学学扎实（面试会问得很细）
- [ ] **开始编程**。Python + NumPy/SciPy，做[计算项目](计算物理/项目清单.md)
- [ ] 英语：六级（保研）、TOEFL（出国，建议大二下或大三上考掉）
- [ ] 有余力：参加数学建模/物理竞赛、大学生创新创业项目

### 大三：分水岭

- [ ] **进组做科研**（最重要，没有之一）
- [ ] 做出可展示的成果：一个项目、一份报告、能讲清楚你在做什么
- [ ] 确定方向（见[出路与规划](出路与规划.md)）
- [ ] 建立 GitHub 与科研档案

!!! warning "大三下是关键节点"
    保研看的是**前三年（或前五学期）的 GPA**，到大三结束基本定型。大四再努力已经来不及。

### 大三暑假：最关键的一段

- **国内**：夏令营（各校 7–8 月）。这是提前拿到 offer 的主渠道
- **海外**：暑期科研（REU、各校暑研项目）。**能去就去**——它直接给你海外推荐信，这是出国申请最强的筹码
- 如果去不了海外，就在本校/国内顶尖组做一段扎实的科研

### 大四上：申请

- **保研**：9 月推免（现在多是 9 月底系统开放），准备面试
- **考研**：12 月统考
- **出国**：11–12 月申请截止（各校不同，多数在 12 月），10 月前要定校、要推荐信

## 四、推荐信怎么拿

!!! note "强推的来源只有一个：和你一起工作过的人"
    "我上课拿了 A+"换不来强推。教授需要能具体说出：你做了什么、遇到什么困难、你怎么解决的、结果如何。

**具体做法**：

1. 跟一位老师做至少**一个学期**的实际工作（不是挂名）
2. 定期汇报进展，让老师知道你在做什么
3. 做出阶段性成果，写成报告
4. 主动提供素材：你的项目总结、代码仓库、一页纸的成果说明（帮教授写出具体的推荐信）
5. **提前一个月**开口，并给足信息

**海外暑研的推荐信为什么值钱**：因为招生委员会认识推荐人、信任其判断，而且推荐人了解国际标准。

## 五、面试会问什么

无论是保研面试还是出国面试，核心都是**考察你是否真的懂**。

**常见问题类型**：

- 专业课细节（"推导一下氢原子的能级""讲讲 Ising 模型的平均场解"）
- 你的科研经历（"你在这项工作里具体做了什么""遇到过什么困难""为什么用这个方法"）
- 基础物理直觉（"估算一下……"这类 Fermi problem）
- 为什么选这个方向、为什么选我们组

!!! tip "准备方法"
    **能讲清楚你做过的东西**，比多背两个公式重要。面试最尴尬的不是答不出难题，而是讲不清自己简历上写的东西。

## 六、常见错误

- **等到大四才准备** —— 保研看前三年成绩，出国看科研积累，都是长线
- **只刷考试不做科研** —— 出国申请中的经典失败模式
- **套磁邮件群发模板** —— 教授一眼看穿，直接删
- **推荐信找头衔最大但不认识你的人** —— 弱推不如强推，"院士给我的课打了 A"没有价值
- **忽视口语** —— TOEFL 口语单项常被单独划线，且直接关系到你出国后的助教工作
- **方向选得太窄** —— 申请时方向太冷门会大幅减少可选导师（见[出路与规划](出路与规划.md)）
